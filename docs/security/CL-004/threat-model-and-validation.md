版本：0.2 · 2026-10-12 · **R0 设计交付已由 A（任宇航）验收；真实安全测试、非作者复核及外部签审按父项记录接续。**

## 实际基线、资产与边界

2026-10-12 代码只有 Web 首页、API 健康接口、`jobs` 表和 Temporal 健康工作流。
`jobs.input/output` 目前是 JSONB，并无业务载荷准入规则；存在字段不表示已支持安全任务。
鉴权、上传、MinerU Adapter、检索、生成、导出、删除和计划链路均未实现；以下场景不是已发现的线上漏洞。
依据为 [ADR-0001](../../architecture/ADR-0001-technology-stack.md)、
[ADR-0002](../../architecture/ADR-0002-repository-and-deployment-topology.md)、
[已确认 P0 范围](../../product/CL-001a-scope-boundaries.md) 和 [后续实现卡](../../roadmap/CanLearn_V2.1_Issue_Backlog.md)。

沿用 a 的 D01–D23：账户/归属 D01–D03，原件/权利/解析 D04–D07，索引/引用/内容 D08–D10，
作答证据/计划 D11–D12，Job/Temporal D13–D14，缓存/临时/导出/凭据 D15–D18，
日志/审计费用与删除记录 D19–D20，备份/供应商/公共发布 D21–D23。

| 边界 | 不可信输入 / 受保护入口 | 必须保留的责任 |
| --- | --- | --- |
| B01 Web/匿名/其他账户 → API | 用户 ID、空间 ID、资源 ID、引用、请求键、计划提案 | API 从身份与权威归属判权限；不能接受客户端自报权限、用途、校验或费用结论 |
| B02 API → 数据库/对象存储/索引/缓存 | 查询条件、对象 key、派生关系、发布或删除事务 | API 权威写入；派生资产继承来源权限与用途交集，返回前复查 |
| B03 API ↔ worker/Temporal | Job 引用、activity 结果、历史、事件、取消/删除信号 | 限范围服务身份；临时结果不能直接成为业务事实；历史属于持久化副本 |
| B04 Adapter → MinerU/模型供应商 | PDF/必要片段、供应商产物、下载地址、重定向 | 仅批准用途和目标；上游结果仍不可信，供应商不能赋予访问或发布权 |
| B05 解析/模型产物 → Web/校验器 | HTML、Markdown、图片、公式、代码、指令 | 数据不能变成客户端脚本、宿主命令或系统指令；计算校验须独立沙箱 |
| B06 下载/导出 → 浏览器/外部持有者 | 签名凭据、导出包、浏览器缓存、转发副本 | 颁发前授权、访问时撤销语义可验证；已下载副本不受平台远程控制 |
| B07 在线系统 → 日志/备份/恢复/支持 | 错误载荷、追踪、Redis AOF、旧快照、临时工单 | 最小记录；恢复开放前应用最新删除记录；支持身份无常驻私有原文权限 |

## 严重程度和放行口径

| 级别 | 判定依据 | 处理要求 |
| --- | --- | --- |
| 严重 | 可信路径可导致跨账户批量私有数据/凭据泄露、宿主执行或服务身份任意外发 | 阻断受影响真实资料接入和发布；不能用性能或时间压力豁免 |
| 高 | 单份私有内容越权、删除后重新可读、未经批准外发/公开、历史事实破坏或重复费用 | 阻断对应功能/用途放行；隔离桩研发可以继续，不扩大到真实资料 |
| 中 | 不暴露内容的受限存在性/元数据泄露、可恢复局部拒绝服务或可见但不可用的错误状态 | 定负责人、期限、监测与受限范围；若可升级到高风险按高处理 |
| 低 | 不影响权限、用途、事实、费用和删除承诺的局部显示问题 | 记录并按产品质量规则处理 |

本稿级别是按最坏可信攻击或故障路径给出的**候选判断**，没有漏洞复现、命中率或剩余风险实测。
同一风险可有不同级别；本轮按其高影响路径设置门禁。下表所列残余风险只是待验证边界，不表示已经降级。
关闭风险需实现证据、负例回归、非作者复核及相应签审；“未测”不能填写“通过”。

## 场景与控制

各场景都需检查正常授权路径，避免仅靠关闭功能取得负例通过。失败预期的错误码、状态和 Schema
由 CL-007/008 定稿；拒绝响应不得带私有内容、对象位置、签名凭据或对其他空间的存在性确认。

### T01 · 猜测资源 ID、跨空间检索/引用/Job/导出（严重候选）

- **主体/前提/路径：** 匿名或合成用户 U-B 得到 U-A 的文档、区块、引用、Job、导出 ID；替换 URL/请求体的 ID 或 `space_id`，通过读原件、搜索、引用回跳、任务输出、取消/重试和导出逐条探测；支持/管理员超出工单范围或授权到期后继续读取。
- **资产/影响：** D01–D02、D04、D06–D13、D17–D18；读出私有全文或答案，取得下载入口，操作他人任务；混合私有/公共来源也可能被错误当作公共输出。
- **预防/检测：** B01/B02 统一服务端资源授权；查询前限制空间，返回、签发、生成与接纳前复查归属/版本/删除状态；Job 权限随目标资源；混合来源输出保持私有。支持访问需有效工单、资源/目的/期限批准和最小审计，无常驻原文权；监测连续越权尝试，审计不含私有内容。
- **失败预期：** 匿名/U-B 得不到 U-A 的内容、答案、任务输出或下载凭据，不能取消/重试/导出；无权、撤回或删除的引用不可读。纠错旧版可按历史读取权限受控回跳，但不用于新检索/生成；授权 U-A 正常路径可用，响应不确认其他空间是否存在资源。
- **合法输入/验证：** 两个合成账户、两个同名空间、每人一份原创 PDF、一个公共候选和一个已发布版本；枚举所有资源操作并置换 ID、空间、过期会话及删除状态。V1 做策略/契约负例，V2 用真实 API、索引和对象存储核对；CL-101/109/110/116/118，R1B 补 CL-206/210/212。
- **责任/阻断/残余：** A 负责统一授权、B 落实各入口、C 回归；设计由 B 非作者审，B 写的端点由 A 非作者复核。任何跨空间内容/凭据泄露阻断对应 R1A/R1B 放行；对象直链和旧缓存另按 T02/T06 验证。

### T02 · 同哈希去重、缓存与索引的存在性泄露（高候选）

- **主体/前提/路径：** U-B 上传与 U-A 字节相同的合成文件，或发相同检索参数；比较命中标记、资源 ID、费用、错误、响应体和反复采样的延迟，随后切空间/纠错/删除再请求旧键。
- **资产/影响：** D04、D06–D10、D15；泄露他人是否持有资料，复用他人解析/索引/答案，或让撤回内容再次成为生成依据；若仅有有限存在性信息可为中，读取内容按严重处理。
- **预防/检测：** B02 的可观察缓存、去重和幂等键含权限域、输入版本与用途；即使底层共享字节也保留独立授权与引用，不向客户端暴露全局命中；检索前/返回前过滤，删除和版本变化使旧条目失效。监测跨域结果和删除后命中，记录不含文件哈希全文。
- **失败预期：** U-B 不能得知 U-A 文件存在，也不能借同哈希读取/计入他人资源；删除 U-A 资源不误删 U-B 的独立合法资源；删除/纠错后旧索引和缓存不进入新结果；不把随机延迟或单次时序相似当作隔离证据。
- **合法输入/验证：** 相同 PDF、同文异字节 PDF、两个相同名称空间、独特合成标记字符串；V1 检查键和查询过滤，V2 并发/冷暖缓存/空间切换/删除后检索并采集脱敏响应和延迟分布；CL-005b/103/109/118。
- **责任/阻断/残余：** B 实现，A 非作者安全复核，C 执行；设计由 B 非作者审。越权内容或可确认他人持有文件阻断真实私有资料；共享设施时序噪声/侧信道需要记录测量与范围，不能声称零泄露。

### T03 · 伪装、损坏、加密和资源耗尽 PDF（高候选）

- **主体/前提/路径：** 恶意上传者将非 PDF 伪装 MIME，提交截断结构、加密文件、异常页数或大尺寸图像；利用准入漏检让解析进程长占 CPU/内存/磁盘，反复重试。
- **资产/影响：** D04、D06–D07、D13、D16、D20；拒绝服务、临时存储耗尽、非预期解析器行为和无界费用；若可执行宿主代码升级严重。
- **预防/检测：** B01/B04 校验实际内容、大小/页数/加密/结构，隔离上传与解析，按请求/用户/进程限制字节、展开量、时间、内存、磁盘和并发；安全失败不派发后续解析；临时目录限额/清理且无执行权限。观测资源超限和永久错误，不将原件写入告警。
- **失败预期：** 不合格输入明确拒绝/隔离，worker 不读取未准入原件；超限解析受控终止，不影响其他合成任务，不无限重试、生成或扣费，孤立产物可追踪清理。
- **合法输入/验证：** 原创最小 PDF 的截断副本、仅含文本的假 MIME 文件、受控加密 PDF、按配置上限 ±1 的页/字节样例；只在隔离环境生成有总量上限的压力输入，不收集真实恶意文件。V1 检查准入分类，V2 用固定 MinerU、资源限制和并发正常任务验证；CL-104/106/114/115/118。
- **责任/阻断/残余：** B 实现准入/Adapter，C 负例执行，A 非作者复核；设计由 B 非作者审。超限不能隔离或可执行宿主代码则阻断解析放行；已知解析器/镜像风险交 CL-013c，具体限制由选型和容量证据决定。

### T04 · 资料指令注入与模型越权调用（严重候选）

- **主体/前提/路径：** 上传者在 PDF/解析块/检索结果加入“忽略约束、读取其他空间、传出凭据、直接发布/改分”等指令，诱导模型把资料内容当作系统授权或调用工具参数。
- **资产/影响：** D04、D07–D14、D20、D22–D23；外发私有数据、越权工具访问、错误发布/改写事实和不受控费用；模型只生成错误文字且未取得权限时为质量问题，不能掩盖潜在工具路径。
- **预防/检测：** B04/B05 分隔系统规则与不可信证据，模型不持有数据库/发布/跨空间凭据；工具按服务端主体、资源、用途及预算独立授权，不靠模型自报；只接纳结构化候选，经引用/权利/质量门再发布。记录拒绝工具原因和模板版本，不记录注入原文。
- **失败预期：** 数据内指令不能改变权限、工具范围、外发目的地或直写事实；缺来源/无权限候选不发布；安全失败不会降低门禁或自动切到未经批准供应商。
- **合法输入/验证：** 原创 PDF 含显式、引用伪装和多语种注入文本，用 U-A/U-B 合成标记、桩工具和受控无敏感接收器检测调用；V1 断言工具拒绝和候选隔离，V2 在已批准网关验证实际模型输出/工具轨迹并加入回归；CL-005c/109/118/205/206/207/210。
- **责任/阻断/残余：** A 负责网关/权限，B 实现生成链，C 测试，B 非作者审核设计与 A 的控制，A 复核 B 的链路。任何未经批准工具调用、外发或写入阻断该生成用途；提示模板仅是辅助手段，有限样例通过不等于模型永不受注入。

### T05 · HTML、公式或生成代码执行（严重候选）

- **主体/前提/路径：** 上传者或模型产物携带事件处理器、脚本链接、嵌入 HTML/图片 URL、公式扩展或计算代码；在双栏阅读、讲解、导出预览或答案校验中被当作可执行内容。
- **资产/影响：** D06–D11、D17–D18；浏览器会话/内容泄露，服务器命令执行、外网连接或校验进程耗尽；外部图片请求也可能向第三方泄露访问元数据。
- **预防/检测：** B05 使用明确允许的展示语法/URL协议并清洗，禁用不必要的原始 HTML/主动 PDF 内容，隔离预览并限制外部资源；公式渲染不接受可执行扩展。计算代码只进无凭据、无外网、限资源的独立沙箱，输出不能作为任意宿主命令。监测清洗拒绝和沙箱超限。
- **失败预期：** 恶意内容呈现为安全文本或明确不可展示，不执行脚本/宿主命令、不请求未批准外部地址；沙箱失败进入待复核，不以执行错误结果发布答案。
- **合法输入/验证：** 合成 Markdown/JSON 包含无害 canary 事件、脚本协议、测试图片地址、公式边界与受控沙箱代码；不使用真实凭据或破坏命令。V1 测清洗/沙箱拒绝，V2 浏览器自动化断言无执行/外网请求且正常公式可读；CL-106/107/112/118/207/209/211。
- **责任/阻断/残余：** B 负责产物和校验、D 负责展示，C 测试，A 非作者复核实现，B 非作者审核设计。不可信资料/解析/模型产物触发客户端脚本或宿主执行，阻断展示/校验放行；浏览器、PDF/公式库及沙箱逃逸的供应链风险交 CL-013c/403。

### T06 · 签名 URL、导出包和撤销窗口泄露（高候选）

- **主体/前提/路径：** U-B 获得 U-A 已签发 URL/导出链接，或 U-A 在删除前下载凭据，删除后继续直连存储；链接出现在 referrer、页面、错误、导出清单或被重复转发。
- **资产/影响：** D04、D06–D11、D17–D18；持有者在授权撤回后仍下载原文/记录；错误导出范围可能连带公开或第三方受限内容。
- **预防/检测：** B06 在打包起始、接纳、领取下载/签发时逐项复查当前授权与导出用途，绑定最小资源/用途，链接和包有明确过期/清理规则；下载路径避免暴露凭据给第三方资源。Q07 必须验证直链撤销能力；若存储无法即时撤销，选择可实时拒绝的受控读取路径，或先解决凭据/对象失效机制，不能仅缩短有效期就称“立即不可读”。
- **失败预期：** 删除立即停止新签发和平台读取；承诺即时撤销的路径对所有在途凭据拒绝。若存在已签发凭据窗口，删除状态单列待失效凭据和预计边界，未达到所承诺不可读条件不能报在线清理完成；已合法下载副本无法承诺平台远程收回。
- **合法输入/验证：** U-A 合成原件/导出包和 U-B 无权限会话，保存删除前 URL，再在删除、撤销、期限边界、换身份后直连下载；V1 用桩定义状态，V2 以最终存储/CDN/代理实测撤销和缓存，V3 验证用户进度文案；CL-005a/103/110/116/117/118/218。
- **责任/阻断/残余：** A 主责、B 实现/非作者验证 A 的方案、C 检测、D 检查界面，设计由 B 非作者审。Q07 未决或凭据仍可读而产品宣称即时撤销，阻断该真实资料下载/删除承诺；期限 Q02 不在本稿擅定。

### T07 · 日志、Temporal 历史与持久缓存的越界留存（高候选）

- **主体/前提/路径：** 支持/运维读日志、Temporal UI 或恢复副本；一次失败让异常文本、activity 输入/输出、heartbeat、search attributes、memo、事件或 Redis AOF 存下原文/签名 URL，在线删除只清业务存储。
- **资产/影响：** D13–D15、D19–D21；未授权二次读取和超过声明范围的持久留存；若包含服务密钥或批量私有原文升级严重。
- **预防/检测：** B03/B07 工作流/事件只传必要资源引用、伪匿名 ID、版本和最小状态；activity 临时授权在执行时获取，完整内容不进历史/失败/心跳/检索属性；异常和追踪字段采用允许列表与脱敏。D15 可缓存经规范批准的最小内容，但须隔离权限域/版本、可枚举清理；AOF 历史物理残留按 Q02/Q03 设计清理及防恢复。Temporal UI/日志访问独立控制与审计，Q09 决定历史留存、访问和清理边界。
- **失败预期：** 合成原文/假令牌触发失败、重试、取消后，日志、历史、属性、事件无原文或可用凭据；合法内容缓存遵守授权与期限，删除后 API 不读/命中被删内容，恢复副本在开放前清理。AOF/备份历史物理残留按批准期限和步骤处理，不承诺删除请求受理时瞬间清除；回执区分阶段。
- **合法输入/验证：** 独特 canary 原文和失效假凭据触发解析/模型/网络错误，再缓存批准内容并删源；V1 验证 Schema/日志序列化，V2 检查实际历史/日志/事件无敏感 canary，删除后 API 缓存不可读、恢复开放前无被删内容，并核 AOF 物理清理阶段证据；CL-008a/008b/011b/013c/114/117/205。
- **责任/阻断/残余：** A 主责工作流/可观测性，C 测试，B 非作者审核。敏感载荷入历史/日志或 Q09 未决定而接真实资料，阻断相关集成；已有错误持久副本需事件处置及受控清理，不能靠修改新写入规则宣称旧副本已清除。

### T08 · worker 服务权限过大与 Adapter 任意 URL/重定向（严重候选）

- **主体/前提/路径：** 泄露/误用 worker 身份或恶意上游产物把下载地址指向内网/本机/云元数据/其他空间对象；经重定向、主机解析变化或不同协议绕过检查，携带服务凭据访问目标并回传结果。
- **资产/影响：** D04、D06–D10、D13–D14、D16、D18、D22；跨空间读写、服务密钥泄露、SSRF、任意外发或绕过质量/发布门禁。
- **预防/检测：** B03/B04 服务授权限定 Job、资源、操作、用途、时效；worker 只读授权输入/写隔离临时产物，API 接纳时重新审核；Adapter 只访问固定批准上游/下载目标，校验协议/主机/端口和每一跳重定向/实际连接目标，拒绝非批准内网目标和凭据跨主机转发；部署层出网限制兜底。记录目标类别和拒绝原因，不记录凭据。
- **失败预期：** 他人资源及权威数据库写入拒绝；非批准地址/重定向在取内容前拒绝，无内网请求和凭据转发；目标未知时停在可人工处理状态，不让客户端指定可信下载地址。
- **合法输入/验证：** 桩供应商返回合成 loopback/私网/元数据形式地址、非法协议、跨主机重定向和受控解析变化；网络捕获仅在隔离测试网，禁止实际访问生产内网/元数据。V1 检查授权和地址策略，V2 用最终 Adapter/网络规则验证并核对连接记录；CL-005d/007/008/106/114/118/205。
- **责任/阻断/残余：** B 负责 Adapter，A 负责服务身份/出网策略并非作者复核 Adapter，C 测试；设计由 B 非作者审。可任意出网、跨域读写或直写业务事实阻断 worker/供应商接入；部署批准内网 MinerU 不等于允许整个私网，目标选型依 Q06/Q05。

### T09 · 取消/删除后晚到结果复活、重复发布或费用（高候选）

- **主体/前提/路径：** 正常用户取消/删除时上游仍运行；网络超时、worker 重启、重复请求/回调/Outbox 重放，让旧结果越过检查，启动新付费步骤、发布已删内容或重复扣额。
- **资产/影响：** D04、D06–D10、D13、D16、D20、D22；删除承诺失效、重复业务结果/费用、无界重试；并发发生不代表恶意用户才可触发。
- **预防/检测：** B02/B03 每步准入及结果接纳查权威取消/删除/权限/版本/用途；步骤准入须与取消/删除原子协调，接纳事务与墓碑/版本条件互斥，不能读取旧状态后无条件开工。幂等键含权限域/输入版/参数/请求键，费用台账和 Outbox/消费去重，孤立产物隔离清理；不能凭 Temporal 重试推定恰好一次。
- **失败预期：** 取消后不准入新费用步骤、不发布；取消前已获准的上游请求属于在途，取消/执行及费用结果须对账，不虚称取消必然零费用。删除优先于晚到结果，新旧重试不能复活；同一业务事件只结算一次，未知供应商取消状态不放松接纳门禁。
- **合法输入/验证：** 合成 PDF/Job/费用事件，在检查后、临时写入后、接纳事务前分别暂停并发删除/取消，再重复回执/重启/事件重放；V1 用确定性桩做时序表，V2 真实 API/数据库/Temporal 故障注入核对状态、资产和账本；CL-008a/008b/008c/114/115/117/118。
- **责任/阻断/残余：** A 主责，B 非作者执行关键竞态，C 记录/回归；设计由 B 非作者审。任何复活、重复发布/扣额或新增未授权付费步骤阻断任务/删除放行；无法撤回上游执行属于 Q05 待决条件，不能解除本地接纳门禁。

### T10 · 旧来源/计划版本覆盖新版与作答事实（高候选）

- **主体/前提/路径：** 用户纠错/更新版本/接受恢复提案后，旧解析/模型结果才返回；重放旧 plan patch、客户端自报约束通过或撤销计划，覆盖新版内容、改分、抹去已完成任务。
- **资产/影响：** D04、D07–D12、D13、D20；来源无法核对，旧答案参与新判分，学习证据/计划被无声修改；资料删除时若作答快照含原文还可能留存被删副本。
- **预防/检测：** B02/B03 不可变输入/来源/题目/答案版本和基版本条件；旧结果标冲突/待复核，不覆写当前事实；计划确认时服务端复算并原子提交，撤销只影响允许撤销的未来安排；纠错/撤回传播失效图。Q04 独立决定主动删除后事实字段与复制原文的清理，不能用“保留作答”保留所有原文。
- **失败预期：** 旧版本不成为新生成依据/覆盖当前版本；历史作答和已完成任务在纠错/计划撤销下保持可追踪，计分失效/重算留记录；主动删除清原文副本并按 Q04 处理事实，不伪装成普通计划撤销。
- **合法输入/验证：** 同一原创资料 v1/v2、题/答案 v1/v2、一次合成作答、已完成/未来任务及两个同基版本提案；乱序返回/重复确认/撤销与删除。V1 验证数据关系和冲突契约，V2 检查数据库事实/失效图，R1B 补确认界面；CL-006b/008/113/212/213/214/215/302。
- **责任/阻断/残余：** B 负责来源/作答，A 负责证据/计划并非作者复核 B 的实现，B 非作者复核 A 的实现，C/D 验证；设计由 B 非作者审。事实覆盖、旧来源继续用于新生成或 Q04 未决而宣称全链路删除，阻断相应功能承诺。

### T11 · 旧备份恢复与供应商残留重新可读（高候选）

- **主体/前提/路径：** 运维恢复早于删除的数据库/对象/索引/Redis/Temporal 快照，同时恢复旧删除台账；供应商继续保留输入/日志，退出/重试时返回旧结果，系统据此恢复访问。
- **资产/影响：** D04、D06–D22；已删原文/派生内容恢复可读，供应商副本超范围留存，恢复后生成再次使用旧来源。
- **预防/检测：** B07 恢复先隔离，取得独立于旧恢复点的最新删除记录，应用后再开放；索引重建和任务重放遵守墓碑/用途，缺最新记录时不开放相应资料。Q03 明确备份到期/恢复责任；Q05 核验供应商地域、训练/分包、留存、删除/退出回执与无法清除的边界，不能用本地删除代替外部回执。
- **失败预期：** 旧快照恢复后被删资料仍不可读/检索/签发/生成；供应商清理未完成单列状态，不报告“所有副本已物理删除”；备份未到期不保证即时物理抹除，已知残留不随恢复变成可用内容。
- **合法输入/验证：** 合成资料在 t1 备份、t2 删除、t3 隔离恢复；保留独立 t2 删除记录，另测缺记录/过期凭据/供应商拒绝或无回执桩。V1 复演恢复步骤，V2 真实备份/供应商条件可用后受控演练，V3 按 CL-402/403 放行复核；前置 CL-005c/005d/117。
- **责任/阻断/残余：** A 主责恢复/供应商，B 非作者执行、C 留证，外部数据/权利责任人签审供应商条件；设计由 B 非作者审。缺可靠最新删除记录、恢复前无法隔离或供应商条件未知，阻断对应真实资料/恢复开放；期限和供应商证明不能在本稿捏造。

### T12 · 未经批准的公共发布、导出或供应商用途（高候选）

- **主体/前提/路径：** 编辑/用户把私有或公共候选改成“公共”，换来源版本后复用旧许可，把允许阅读的材料用于复制/模型处理/分发；模型从私有+公共来源生成后公开，或网关降级到未审核供应商。
- **资产/影响：** D04–D05、D08–D10、D17、D22–D23；超批准用途外发、公开受限素材和学习记录；类别、可访问网页、用户声明或字体许可不能自动证明所有用途获准。
- **预防/检测：** B02/B04 发布/导出/外发独立按主体、来源版本、用途、证据和审批状态检查；多来源取权限/用途交集，候选与公开版本分开；来源/许可变化重新审核，不靠 UI 隐藏按钮；供应商未知只用合成资料/桩，网关故障不跨审批边界降级。记录审批版本和拒绝理由，不在公开台账放受限原件。
- **失败预期：** 未签审/用途不匹配保持不可发布/外发/导出；本人可读不等于可公开或交供应商处理；公共发布撤回停止新取用；合法已批准范围正常执行。
- **合法输入/验证：** 原创合成素材的“允许私读/禁止外发”“允许模型处理/禁止公开”等**测试策略标签**，无真实法律断言；两个供应商桩（一批准、一未知）和混合来源候选。V1 验证策略矩阵，V2 联通发布/导出/网关负例，真实素材和供应商按证据签审后才测试准入；CL-004b/005c/009a/010a/116/202/205/207/208/406。
- **责任/阻断/残余：** A 管理权利/供应商，B 实现用途门禁，C 维护台账，外部权利/学科负责人按用途签审，B 非作者审核设计、A 复核 B 的实现。缺来源或用途审批阻断对应外发/发布，技术绿灯不能替代权利判断；具体许可证问题依 Q08，不给法律结论。
