## 1. 已有状态与判定原则

当前 API 只有健康接口，`jobs` 表没有主体、资源归属和来源版本字段；Python 只有健康工作流。
下表及检查点均为后续实现约束，**现有工程尚未实现鉴权、资源隔离、权利审核或删除传播**。
不改现有业务代码、契约、迁移或服务边界；主 API 管理权限、业务事实与发布，worker/MinerU 负责受限处理。

1. 默认拒绝：没有明确允许规则或证据不足时，不执行对应操作；注册、付费和上传不扩大素材用途。
2. 服务端从认证主体和权威资源关系确定归属；客户端 `space_id`、对象键、哈希、Job ID 和引用不能证明授权。
3. 私有资料默认仅本人使用，不公开、不训练、不被其他私有空间检索；P1 共享与 P2 机构权限不在本轮开启。
4. 每次授权同时判断主体、资源/版本、操作、目的、状态、权利范围及有效期；不能以首次上传的检查代替后续检查。
5. 所有派生资产继承来源权限域、版本和用途限制；多来源输出取所有来源的权限与用途交集，不取最宽权限。
6. 私有与公共来源混合产生的讲解/练习留在私有域。公共来源可读不意味着原件、答案、索引或后台草稿可读。
7. 权限审核与来源权利核验分开，权利通过也不代替学科审校；用户纠错、模型置信度或技术评审不能自动批准发布。
8. 删除先撤销访问与新增处理，再清理副本；取消 Job 不等于删除资料，纠错/计划撤销不改写历史作答事实。

规则中的“允许”表示满足列出的设计条件后允许，不表示已上线。资产状态沿用 004a 的概念生命周期；
精确实体、状态名、错误码和事务规则由 CL-006/007/008 定稿。

## 2. 主体与可访问空间

| 主体 | 可进入的权限域与资源 | 默认禁止 / 附加条件 |
| --- | --- | --- |
| 本人（已认证） | 自己的 D01–D03；自己私有域 D04–D13 的本人可见字段及经授权的 D17/D18；对本人可用的 D23 发布版本 | 不能读取他人资料、学习记录、任务或来源；访问自己的资产仍需检查用途、删除和版本状态 |
| 其他已认证用户 | 自己的私有域和获准的公共发布版本 | 对他人私有资源一律拒绝；同学科、同名概念、相同哈希、已知道 ID 都不形成权限 |
| 公共内容学习用户 | D23 中面向该用户发布的内容、公开来源元数据；本人 D11/D12 | 不继承公共源原件或审校后台权限；练习/诊断用途、答案显示时点按发布版本与学习会话控制 |
| 匿名请求 | 已发布且明确标记允许匿名读取的 D23 展示版本与公开元数据 | 未明确匿名受众的内容默认拒绝；不得读取私有资产、触发有账户成本的解析/生成或导出学习记录 |
| 公共内容编辑 / 学科审校者 | 被指派的候选域 D04–D10、D23 审核记录；仅所需版本与用途 | 角色不附带全部私有空间权限；编辑提交候选，不能独自批准自己写的高风险内容或替代权利签审 |
| 支持 / 管理员 | 常规只看工单、必要状态及脱敏 D19/D20；基础设施管理权限单独分配 | 无常驻私有原文/作答读取权；例外支持须明确工单、必要资源、目的、期限、批准与审计；故障不自动豁免 |
| 受限 worker / Adapter 服务身份 | 主 API 为具体 Job 授权的 D03/D04/D06–D12 最小约束或片段；D17 仅指定打包清单；写 D16 临时产物 | 不枚举全库、不自由修改归属/权利/事实、不直接公共发布；评分只取必要题/量规/作答，计划只产候选；范围、有效期、目标与结果接纳均受限 |
| MinerU / 模型供应商 | 经网关/Adapter 核验允许外发的最小 D22 输入；仅指定目的的处理副本 | 不是平台账户或数据管理员；无浏览、跨空间检索、训练或再分发权；未知供应商条件不接真实私有资料 |

D14/D15/D16/D19–D22 为内部处理资产，不因用户持有其 Job ID 就原样向其开放。
用户可见状态、费用和删除进度通过 API 提供必要投影；底层日志、错误栈、供应商载荷和工作流历史不作为下载内容。
管理员查看 Temporal UI、索引控制台或备份同样需要最小运维权限，不能成为绕过业务授权的私有内容入口。

## 3. 资源与操作规则

| 资源 / 操作 | 本人私有域规则 | 公共 / 内部域附加规则 |
| --- | --- | --- |
| D01/D02 账户、空间归属读写 | 本人读改允许的账户字段；归属由服务端维护，不能提交别人的账户为所有者 | 运维不得修改归属以取得内容；成员/共享功能后置，不能据现有表名推定已支持 |
| D03 目标与容量创建/修改 | 本人操作；跨目标共享容量仍只在本人域校验 | 公共学科配置不读取其他人的容量与目标 |
| D04 创建/上传 | 主 API 检查本人、准入、目的和 D05 来源记录，绑定不可变来源版本 | 公共候选需明确负责人与来源用途；上传不自动成为公共资产 |
| D05 声明、许可与审核记录 | 本人读自己的声明和可提供的用途结论；改声明形成新记录，不能自写“审核通过” | 指定审核人核验受控证据；他人合同/身份附件、内部审批记录不随内容公开或导出 |
| D04/D06 读原件、页图与解析全文 | 本人且指定版本未撤回/删除、阅读/复制用途有效；旧版仅允许受控历史回跳 | 公共学习用户仅能读明确发布的范围；原件、扫描图和完整解析需独立允许，不由引用自动开放 |
| D04/D06/D07 解析/标准化 | 本人发起受限 Job，核验存储解析用途、外发条件、质量与额度 | 编辑只处理获准候选版本；worker 不自行选择不满足数据边界的备用供应商 |
| D07 修改/纠错、D09 关联 | 本人提交修订，新修订记录基版本及依赖；旧版不可静默覆写 | 公共用户提交工单，编辑/审校按指派复核；同名节点不自动合并权限或学习证据 |
| D08/D09 检索与引用回跳 | 仅本人可用来源的有效版本；返回前检查每条命中与引用目标 | 公共检索仅已发布范围；候选/撤回/删除版本不参与；索引条目不是独立授权来源 |
| D10 生成讲解/练习/量规 | 核验全部来源可用于本次生成、供应商及目的；输出留本人的权限交集 | 公共来源生成供本人练习不等于可发布；诊断与教学/答案检索上下文分开 |
| D10/D23 发布与撤回 | 私有可用只表示对本人通过相应质量门；不能将私有资产直接改空间为公共 | 公共需来源权利、学科审校和指定用途/版本记录；撤回由内容责任路径执行并阻止新读取/检索/生成 |
| D11 作答与证据读写 | 本人提交；API 校验题版本、会话及用途，写事实与修订记录 | 编辑/支持不常规读取个人作答；公开统计需另审范围，不公开个体证据 |
| D12 计划确认/撤销/恢复 | 本人确认基版本差异；撤销只影响可撤销的未来安排 | 模型和 worker 仅给候选提案；无权确认或改写已完成事实 |
| D13 Job 读取、取消、重试 | 除 Job 归属外，检查目标资源、来源版本、目的与当前删除/撤回状态 | 编辑仅操作被指派候选；Job creator 字段、工作流 ID 或查询端点不能单独授权；重试重新检查 |
| D17/D18 下载、导出 | API 逐项核验本人数据与素材导出权，清单写版本/范围；领取时再次授权 | 公共用户仅得许可允许导出的已发布范围；不夹带后台答案、他人内容、日志或供应商副本 |
| D04 等资料删除、D01 账户删除 | 本人经相应身份确认申请；API 锁定范围，撤销新访问并调度全链路清理 | 支持可协助受控请求，不能任意删除他人事实；公共来源撤回与本人账户删除分开 |
| D14–D22 内部清理/恢复/审计 | 用户取得状态投影和可导出的自有记录，不直接读改内部存储 | 清理/恢复服务按指定范围执行；恢复先应用删除记录；审计例外范围/期限需 Q02/Q03 明确 |

这里“取消”专指取消受限任务；“撤回”指停止某发布版本的新使用；“删除”触发资产与副本清理。
三个动作不可混用状态或完成回执。D11 的历史事实与其中复制的原文分开处理（Q04），
旧引用可显示失效原因和必要元数据，不能因此恢复原件或继续向模型提供原文。
纠错后的旧版若仍满足本人访问、来源权利及删除状态条件，可按明确版本查看历史依据；
这不允许旧版进入新检索/生成。撤回/删除版本只提供必要失效提示，不能借历史回跳恢复读取。

### 必须复查授权的处理点

| 检查点 | 必须读取的权威条件 | 失败行为 |
| --- | --- | --- |
| API 请求入口 / 列表与详情 | 认证主体、资源归属、操作与目的；不存在/无权返回一致的非泄露响应策略 | 不返回名字、页数、状态或缩略图等私有存在性信息；错误契约由 CL-007 固化 |
| Job 提交 / 每步开工 | 目标资源、来源版本、删除/撤回/取消、用途许可、预算及供应商资格 | 不启动新读写/外发/计费步骤；记录最小拒绝原因 |
| 检索 / 缓存命中 / 引用展示 | 权限域、新检索的当前可用版本或历史回跳的指定允许版本、发布受众、用途、删除/撤回标记 | 无权条目不进入证据包；返回前逐条验证，不能把全库结果过滤交给前端；历史回跳不恢复新生成资格 |
| 模型 / MinerU 外发前 | 本次最小输入、来源用途、地域/留存/训练等供应商核验状态 | 未满足条件不传出；不静默切换到外部后端 |
| 结果接纳 / 发布事务前 | Job 授权仍有效、基版本一致、所有来源仍可用、权利与质量门禁有效 | 拒收晚到/旧版/用途失效结果，隔离并清理 D16；worker 成功不自动成为业务成功 |
| 导出生成 / 领取下载 | 清单全部项目的当前授权、版本与导出范围；下载凭据作用域和撤销状态 | 拒绝越界项目或使整包失效，明确结果；不能以导出创建时的权限继续领取已撤销内容 |
| 支持临时访问 / 恢复环境开放 | 有效工单批准/服务范围，或删除记录已重放且禁止访问验证满足 | 过期授权不继续访问；恢复环境未经检查不接用户流量 |

主 API 必须把检查与业务写入/发布协调，防止检查后删除或许可失效仍提交；具体锁、版本比较、
授权修订号和幂等键由 CL-006/008 决定。worker 只能取得短期、限定资源和操作的能力，不能沿用一份永久全库密钥。
付费步骤准入须与取消/删除权威状态原子协调；取消前已获准进入的上游请求计为在途，不能承诺零费用，
取消/删除后不新增处理步骤，既有消耗按 CL-008/114/115 的公开规则核对。
D14 工作流 history/activity/heartbeat/memo/failure/search attributes 不保存原文、题目答案、完整对话或 D18 凭据；
用内部资源引用和最小状态，引用取数时再授权（Q09）。事件和日志遵循同一限制。
D13 的版本化事件/Outbox 与传递副本只含必要元数据，重放仍复查目标资源状态；
本人任务摘要不开放内部事件载荷或消费控制，业务事件当前尚未实现。

### 缓存、去重与可控下载

- D08/D15 的键与命中规则至少包含权限域、来源/修订版本、处理参数和用途；生成缓存还包括必要模型/模板版本。
  缓存过期不代替删除传播；读取缓存前仍查权威删除/撤回状态，无法确认时不返回内容。
- 私有文件只在同一权限域复用可复用产物；跨私有域不得通过哈希返回解析文本、文件 ID、上传节省或命中差异。
  如内部考虑物理去重，必须独立证明逻辑权限、引用计数、删除与存在性信息隔离，不能作为 P0 默认获准行为。
- 公共缓存仅复用具有共享许可且已发布的具体版本/用途；发布撤回、许可变化或修订使对应缓存失效。
  私有与公共混合结果不能进入公共缓存，日志不能记录完整哈希后供无关用户查询。
- 客户端只通过 API 取得受控下载资格，不自行拼接对象键。代理读取或签名下载的具体方案由 Q06/Q07 决定。
  D18 仅限资源/版本/动作，最短必要有效期待定；不放日志、分析事件、工作流历史或公开链接。
- 删除/撤回停止签发并失效 API 管理的凭据。若存储签名 URL 不能即时撤销，必须记录残余可读窗口和补偿方式，
  不能承诺“删除后立即任何路径不可读”；未满足承诺的删除语义前该访问方案不得放行。
  本机已下载副本不能由服务端保证远程清除（Q07）。

## 4. 素材类别与用途证据

来源权利记录 D05 绑定 D04/D23 的具体版本，包含来源/作者、取得方式、证据指针与核验日期、
主体/地域/有效期、逐项允许用途、署名及再分发条件、撤回/争议状态、核验人与签审记录。
受限合同、真实资料和个人信息留在受控存储，仓库只保存脱敏模板/证据指针，不复制全文。

下表每一列独立核验。“待核”表示没有足够凭据，不是允许；“拒绝”表示超出当前记录范围。
取得阅读权、公开网页可访问、用户自述“用于学习”、模型重新措辞、字体许可均不能代替其他列证据。

| 素材类别 | 读取 | 存储与解析 | 模型处理 | 生成内容 | 公共分发 | 导出 |
| --- | --- | --- | --- | --- | --- | --- |
| 私有上传（笔记/讲义/教材等） | 记录取得方式与本人使用范围；仅本人的域 | 核验托管/复制与解析用途，绑定版本；用户声明先作线索 | 核验所需内容传出、供应商处理安排；默认不训练 | 核验摘录/改编/原题提取等本次用途，留私有 | 默认拒绝；需另走具体来源与版本审核，不能一键改空间 | 自有记录可导；来源原件与派生须逐项有下载/导出范围 |
| 团队原创 | 作者/创作记录、引用与第三方组成清单 | 核验作者对平台托管/解析的权利安排 | 核验模型处理及其第三方组成限制 | 记录原创/AI 生成/提取类别与来源、校验 | 权利范围与学科审校明确后发布指定版本 | 核验是否允许复制/再用，保留署名与范围 |
| 合作方原创/授权内容 | 明确版本合同及签约方权限 | 核验合同的复制、托管、技术处理范围 | 合同/补充许可与供应商条件同时允许 | 核验演绎、出题、答案/解析使用范围 | 核验受众、地域、期限、收费/再分发及审校 | 核验合同的下载、离线与下游再用范围 |
| 开放许可内容 | 原始来源、版本和完整许可凭据 | 核验具体复制/处理条款与组成资产许可 | 核验处理方式、第三方传输及可能限制 | 核验改编/商业用途、署名和继承条款 | 按具体许可与学科审校核验；不能仅按“开放”标签发布 | 保留必要署名/许可，核验导出格式及再分发条件 |
| 商业教材、培训材料、题库/真题解析 | 核验本人取得与阅读资格 | 另核验平台复制/托管/解析范围 | 单独核验外发处理；未核则拒绝传出 | 核验原题提取、答案解析复用及衍生用途 | 未取得适用公开许可则拒绝 | 不能以购买阅读资格推定平台批量导出或再分发获准 |
| 官方公开信息 | 保存原始出处、日期、版本和事实引用范围 | 存全文/图片/版式另核验，不默认开放复制 | 核验拟发送的实际内容，不把公开访问当外发凭据 | 区分事实整理与复制原文/图表，记录来源 | 事实导航与内容复制分别审核；学科/用途审批仍适用 | 原文/图表复制导出独立核验，链接与必要元数据也记录范围 |
| 外部链接 | 只做已审导航或用户自行访问；不绕登录/访问限制 | 链接登记不等于可抓取、下载或托管全文 | 不能把网页抓取后默认送模型 | 不默认为链接目标有生成授权 | 公共导航与发布目标正文分开审核 | 默认仅允许获准的链接/元数据；目标文件另审 |

用户已下载、材料无水印、来源是学校/出版社/考试机构、互联网搜索可见均不是全用途凭据。
同一材料允许私下阅读但未获外发、导出或公开分发时，只启用已证实的用途，其他操作保持待核/拒绝。
如果来源版本、许可证、合同、组成资产或使用目的变化，旧核验记录不能覆盖新用途（Q08）。
CL-003 合成烟测素材及所用字体的既有记录仅供 CL-009a 逐项核验，不能在这里写成已通过外部评测或公开分发签审。

### 公共候选、发布版本与用途升级

| 记录阶段 | 可见主体 / 可执行用途 | 升级所需记录 |
| --- | --- | --- |
| 公共候选 | 被指派编辑/审校者；仅已获准的内部解析、质量检查 | 来源版本与用途核验、候选生产记录；未审不得进入公共检索或普通用户下载 |
| 私有可用 / 基础生成练习 | 本人；限有效来源及清楚标识的练习用途 | 结构/引用/可答性等基础校验；无来源补充明确标识，不能伪造引用 |
| 公共已审校发布版本 | 规定受众与允许展示/练习用途 | 来源权利签审与对应学科审校、版本/范围/署名/有效期和发布记录 |
| 新退出测 / 结构化回忆 | 获准学习会话；内容有效，记录提示/答案曝光、技能/来源版本与可信结果 | 作为学习证据记录等级与限制；答错也可形成 VLU，不能自动视为已掌握或精确概率；具体可信/未泄题规则交 CL-011/208/209/212/213/217 |
| 正式强诊断用途 | 获准诊断会话；诊断题与教学/答案上下文隔离，记录曝光与用途控制 | 适用学科审校、用途批准及相应校准/验证，不能仅凭基础校验、VLU 发生或模型自评分升级 |
| 撤回/过期/争议版本 | 编辑处理工单；本人历史记录仅必要失效提示 | 停止新展示/检索/生成，处置已派生产物；再次发布需新有效审核记录 |

公共发布的署名、许可、学科记录附在具体版本，而非永久批准整个来源或整位作者。
新版本、更换供应商、用途升级、许可到期/撤销和权利争议分别触发复核；正文改动后不得沿用旧版学科签字。
目前没有实际来源权利人和公共学科签审，本稿只支持隔离研发及合法合成走查；真实资料处理与公共发布
在具体来源/供应商核验和相应责任签审完成后按获准范围启动，不要求等待所有后续业务证据才开展设计。

## 5. 供应商处理核验（D22）

MinerU 部署方式、模型服务和索引服务都按实际接收数据的组件核验；“自建”不自动免除其依赖、遥测、
日志、远程 API 或运维访问检查。本轮未选供应商、未传真实资料，以下状态全部为 **Q05 待核验**。

| 核验项 | 最少证据与允许条件 | 未知或失败时 |
| --- | --- | --- |
| 目的与最小输入 | 明确解析/生成/检索用途、数据类别、页/片段范围；确认不需身份和完整学习档案 | 缩减至合成输入/桩服务，不发送真实资料；不能默认整份 PDF/全部作答必要 |
| 实际接收方与版本 | 法人/服务/部署版本、合同/政策核验日期、独立模型/依赖许可记录 | 不以“当前最新”或品牌名称替代版本与条件核验，交 CL-005c/010a |
| 地域与访问 | 传输/处理/日志/备份地域、控制台权限、密钥管理、运维访问方式 | 不推定本地 Compose 地域就是外部或生产地域；未满足要求则禁用该路由 |
| 留存与训练 | 请求/响应/日志/缓存/备份留存，训练及人工审阅用途，关闭方式与适用例外 | 默认不获训练授权；无可核验条件则不接真实私有资料 |
| 分包与继续传出 | 子处理方、数据类别与地点、变更通知、限制的传递及批准路径 | 不允许未经核验的备用模型/重试路由或分包对象接收真实内容 |
| 删除与取消 | 请求入口/时限/副本范围/备份例外、失败重试、删除回执或其他可核验证据 | 回执不足标记外部清理未证实，不能把 API 删除成功写成供应商已清除 |
| 安全与故障 | 传输/存储保护、访问隔离、泄露通知、最小错误信息、取消后费用和晚到结果 | 返回故障不含原文/凭据；事故与费用路径交相应负责人，不能放宽权限门禁 |
| 退出与迁移 | 停止调用、撤销密钥、提取必要记录、删除/到期证明、供应商失效替代方案 | 替换方重新核验；不能因退出困难继续扩大传出或恢复被删内容 |

核验登记最少含：负责人、审核人、证据指针、版本/日期、获准数据/目的/地域/期限、残余限制和复核触发。
个人数据处理安排与具体许可证适用由外部责任人核验；本稿不判断未经核实的法律效力，也不把政策标题当履约证明。
真实资料接入前 CL-005c 给出可用供应商/禁用路由及签审记录；技术调用成功只能证明接口运行。
