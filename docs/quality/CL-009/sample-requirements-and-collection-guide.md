# CL-009 · 样本需求清单与收集指南

状态：**收集执行指南；外部合法样本 0 份 / 0 页，CL-009 保持 blocked** · 版本：1.0 · 2026-11-10

对应 CL-009 #9 / #39 / #40 / #41。本文用于安排真实样本的寻找、核权、登记、抽页和交付，
不代替[既有样本准入与分层计划](../../benchmarks/CL-009/admission-and-sampling.md)、
[逐页与引用真值协议](../../benchmarks/CL-009/annotation-protocol.md)及 Issue 验收。
文中数量全部是**待收集目标**，不是已取得量；R2 仅为后续扩样规划，须待项目阶段变化后执行。

## 1. 硬门槛与交付边界

1. **未核权或许可的样本不得入仓库/公开 issue。** 可公开下载、可阅读、已购买或注明出处，均不等于已获复制、解析、内部标注、供应商外发或公开再分发许可。
2. 候选资料在核权前只登记最小元数据和公开来源主页，不下载、不转存正文，不在公开 Issue 粘贴正文、截图、签名 URL、合同、个人信息或受限存储地址。
3. 原件、权利凭据和含原文的标注保存在获批的受控存储；仓库只保存获准公开的脱敏登记、内部证据引用和核权状态。内部引用不得包含可直接访问原件的临时凭证。
4. 每份样本分别核验内部解析、内部人工标注、内部生成/评测、外部供应商处理、公开夹具/Issue 展示等用途。一个用途获准不自动放行其他用途；未决、到期或撤回即为阻断。
5. 不得以原创合成夹具、重复版本、同一 PDF 的拆分件或未经许可真题凑数。性能夹具、失败页和空白页不得用来稀释真实质量分母。
6. C 负责收集和最小登记，A/指定权利负责人核权，B/C 后续独立双标，指定学科审校者仲裁。实际人员未指派时对应签审保持 `pending`。

## 2. 样本计数与准入单位

- **份数按文档家族计数。** 同一原件的扫描版、文字版、勘误版、重排版及内容近重复版本属于同一家族；只能为一个家族目标计一份，各版本仍分别登记 SHA-256 和用途。
- **页数按请求评测页计数。** 同时记录原件总页数与明确的 PDF 页序清单；PDF 页序从 1 开始，印刷页码另记。封面、目录、空白页和失败页若在请求清单中，均保留状态和分母。
- 每份目标约 10 页，允许在 8—12 页内按完整章节、题组或实验单元调整，但须保持各层总目标及实际缺口可见。不得只抽容易解析的页面。
- 样本须为真实教学、学习或考试辅导材料；至少包含可定位的正文，并按层覆盖公式、表格、双栏、图文、题组、跨页材料等难点。同一来源站点或同一作者不默认构成不同家族。
- 收集人先冻结候选版本再登记；核权完成后由第二人复核文件哈希、页数、学科和用途。文件变化必须新建版本，不能覆盖原记录。

## 3. R0 分层目标：约 12 份 / 120 页

408 的四个方向各一份；CET4、CET6 各一份；其他学科选择数学、物理、化学、生物四类。
各层页数可因合法材料实际情况调整，但**学科份数、408/CET 细分覆盖和三种 PDF 类型不能静默取消**。

| 学科层 | 细分要求 | 目标份数 / 请求页 | PDF 类型与内容要求 |
| --- | --- | ---: | --- |
| 408 | 数据结构 | 1 / 10 | 文字版；算法、代码或伪代码、表格至少一类 |
| 408 | 计算机组成原理 | 1 / 10 | 扫描版；图示、公式或表格 |
| 408 | 操作系统 | 1 / 10 | 文字版或混合版；双栏、流程图或题组 |
| 408 | 计算机网络 | 1 / 10 | 混合版；协议图、表格或跨页题组 |
| CET | 四级 | 1 / 10 | 文字版或混合版；长文、阅读顺序、题组 |
| CET | 六级 | 1 / 10 | 扫描版或混合版；双栏、跨页材料、题组 |
| 其他 | 数学 | 2 / 20 | 文字版与扫描/混合版各至少一份；公式、推导、定理或证明 |
| 其他 | 物理 | 2 / 20 | 文字版与扫描/混合版各至少一份；公式、单位、图表、实验材料 |
| 其他 | 化学 | 1 / 10 | 任一真实类型；化学式、反应式、表格或实验题组 |
| 其他 | 生物 | 1 / 10 | 任一真实类型；图文混排、图表、实验材料或题组 |
| **合计** | **6 个学科层，含 4 个其他学科** | **12 / 120** | **全集文字版、扫描版、混合版各至少 2 份** |

执行时另做一张类型交叉表，确保 408、CET 和其他学科三组每组都至少有文字版与扫描/混合版，
且全集同时覆盖三种类型。不得仅在最容易取得的数学或 CET 中集中所有困难样本。
每份请求页至少包含一个完整语义单元；跨页题组必须收齐成员页，不能为凑 10 页截断。

## 4. R2 分层目标：约 60 份 / 600 页

R2 只预登记扩样结构，**当前不启动收集放行，也不表示 R0 已完成**。启动前须重新确认项目阶段、
R0 失败分布、许可范围和独立标注能力，再冻结最终类型配额；不得简单复制 R0 家族扩大份数。

| 学科层 | 细分配额 | 目标份数 / 请求页 |
| --- | --- | ---: |
| 408 | 数据结构、组成原理、操作系统、网络各 4 份 | 16 / 160 |
| CET | 四级、六级各 4 份 | 8 / 80 |
| 数学 | 覆盖不同家族、公式密度和版式 | 10 / 100 |
| 物理 | 覆盖不同家族、图表和实验材料 | 10 / 100 |
| 化学 | 覆盖反应式、表格和实验题组 | 8 / 80 |
| 生物 | 覆盖图文、图表和实验材料 | 8 / 80 |
| **合计** | **同 R0 六个学科层** | **60 / 600** |

R2 全集以文字版、扫描版、混合版各约 20 份为规划起点；每个学科层须包含至少两种类型。
新增学科、新地区考试材料或新版式另建层，不挤占既有 408/CET 和其他学科配额。
R0 合格家族可计入 R2 对应层，但仍只计一次；R2 必须报告新增家族数、延续家族数和各层实际页数。

## 5. 合法来源清单与证据要求

按下列顺序寻找，不以搜索引擎结果、网盘转载或“仅供学习”声明作为授权证据。

| 来源类别 | 可执行收集方式 | 入库前必须留存的证据 |
| --- | --- | --- |
| 团队/合作方原创 | 明确作者与权利人，取得覆盖本次用途的书面授权；登记版本和允许保存域 | 作者/权利人、原创或权属声明、授权文本内部引用、用途、期限、撤回条件、签审人/日期 |
| CC 许可 | 从作者或权利人的正式发布页取得具体作品，保存许可名称、版本和原始链接 | 作品与版本对应关系、完整许可条款链接及快照内部引用、署名要求、是否允许改编/再分发、各用途核验结果 |
| 公共领域 | 核对具体版本、权利状态及适用司法辖区，不因年代久远或政府网站发布直接推定 | 公共领域判断依据、版本来源、适用地区、核权人/日期；无法确认时保持 `pending` |
| 明确授权 | 向教材作者、学校、教师或出版方逐项申请内部解析、标注、外发和公开用途 | 授权主体与权属、授权范围、地域/期限、原件保存权限、派生物/模型供应商限制、撤回和删除条款、凭据内部引用 |

许可含署名、相同方式共享、非商业或禁止改编等条件时，逐项交由权利负责人判断具体用途，
不得自行改写成“已获全部许可”。公开渠道只能保存来源 URL 和核权状态；许可截图、合同全文等
是否可公开须另行确认。授权到期、主体无法确认、版本不对应或权利撤回时，立即停止新增处理并登记清理范围。

## 6. 每份样本的登记字段

收集人先建立 `candidate`，核权完成后才能改为 `admitted`；任何必填项未知均不得猜测或留成默认通过。
实际收集使用既有[外部样本台账](../../benchmarks/CL-009/external-samples.csv)及
[登记表](../../benchmarks/CL-009/corpus-manifest.json)，字段不足时在受控补充记录中保存并建立内部引用。

| 字段组 | 必填内容 |
| --- | --- |
| 身份与版本 | `sample_id`、`family_id`、`source_version`、版本日期、原件 SHA-256、来源 URL/内部来源引用、重复/近重复关系 |
| 学科与类型 | 一级学科、408 四方向或 CET4/6、具体主题；`text` / `scanned` / `mixed`；语言、单双栏及主要困难标签 |
| 页与请求范围 | 原件总页数、请求评测页数、逐页 PDF 页序、印刷页码映射、选页理由、完整题组/跨页关系 |
| 原件存储权限 | 受控存储内部引用、允许保存的位置、可访问角色/最小权限范围、是否允许下载/复制、保留期限、删除与撤回要求；不得填写公开路径或签名 URL |
| 权利与允许用途 | 来源类别、许可证/合同版本及内部证据引用、权利人、核权人/日期；内部解析、内部标注、内部生成/评测、外部供应商、公开登记、公开原件/截图、公开派生物分别为 `allowed` / `denied` / `pending` |
| 数据划分与状态 | `development` / `fixed_regression` / `holdout`（R0 至少标前两类与候选留出状态）、分配版本和理由；`candidate` / `admitted` / `blocked` / `withdrawn` |
| 缺口与复核 | 未覆盖类型、核权问题、许可到期日、第二人复核结果、后续责任人；没有责任人时写“待指派”，不能写虚拟姓名 |

扫描版指正文主要为页面图像、需 OCR 的 PDF；文字版指主要正文具有可用文本层的 PDF；
混合版指同一文档中文字层与扫描图像均占实质部分。类型由人工抽页检查确定，不能只凭文件名或解析器是否输出文字判断。

## 7. 从候选到可评测的执行流程

1. **建候选卡：** 只填来源、学科、版本和所需许可，不取得受限正文；查重并归入家族。
2. **核具体用途：** 对照第 5 节收集凭据，逐项标记允许用途。核权前状态保持 `candidate/pending`。
3. **受控收原件：** 仅在原件保存权限明确后存入获批位置，限制访问；计算 SHA-256，记录真实总页数并人工判定 PDF 类型。
4. **冻结版本和抽页：** 按第 2、3 节选完整语义单元，形成显式请求页清单；第二人复核页码、题组和家族查重。
5. **登记与放行：** 填齐第 6 节字段，由权利负责人签审。只有所需用途为 `allowed` 且复核完成，才进入对应处理；公开用途另核。
6. **标注与烟测：** 按既有协议先以同一份 2 页样例走通独立双标、差异清单和仲裁，再扩到全部请求页。双标未完成不得宣称正式质量验收。
7. **持续失效处理：** 文件修订新建版本；许可变化、撤回或到期立即标 `blocked/withdrawn`，停止后续用途，并追踪真值、缓存、导出及供应商副本的保留或清理。

每个收集批次结束须报告实际候选数、获准数、拒绝/待核数、获准份数/页数及逐层缺口。
目标未达时保留空缺，不用未许可材料、重复版本或合成页补齐。

## 8. 标注协议执行需求

标注以锁定 `source_version + sha256 + 请求页清单` 为单位，原始真值和规范化结果均带 `protocol_version`。
两名标注者独立查看原件，不先看模型输出或彼此结果；争议保留双方原记录、仲裁依据和最终真值版本。

| 需求 | 每页/每对象必须形成的结果 | 合格性边界 |
| --- | --- | --- |
| 文字版/扫描版 CER | 有参考文字页保存原文真值、Unicode NFC 规范化结果、编辑距离和 CER；宏/微平均及学科分层可重算 | 默认保留标点、大小写、数字并固定空白策略；参考为空不除零，空白页误产文字单列；扫描 OCR 与文字层提取分别报告 |
| 阅读顺序 | 区域 ID、规范化 bbox、页宽高/旋转、区域先后偏序及可比较对 | 按违例对数/可比较对数评估；双栏、插入框、脚注不能仅因“文字齐全”判合格，不可比较对不进分母 |
| 公式合格性 | 数字、变量、上下标、符号、运算结构、单位逐项结果及原件区域 | 图像公式与 OCR/文本公式分开；语义错误、漏项不合格，不只比较 LaTeX 字符串 |
| 表格合格性 | 行列、合并单元格、标题/单位、单元文本及跨页关系 | 错行、漏行、错配、跨页断裂单列；不支持类型显式标记，不删除 |
| 题组结构 | `group_id`、材料、题号、子问、答案/证据关系及全部成员页 | 缺材料、错配子问、跨页断组均不合格；缺页标 `missing`，无答案不能由低相似度推断 |
| 版本—页—区域回跳 | 文档版本、SHA-256、PDF 页、区域 bbox；需要时附文本 span 和证据支持判断 | 人工确认能回到锁定原件且支持对应内容；旧版、越域、撤回、伪造编号和非支持证据均失败 |
| 空白/失败页状态 | 每个请求页恰有一个主状态：`success` / `blank` / `failed` / `missing` / `unsupported`，附失败原因和可用子范围 | 空白不等于失败，失败/缺失不剔出页覆盖分母；无参考文字页在 CER 报 `N/A` 并同时披露数量 |

复杂页保留原件区域和失败类型。任何阈值在实际合法样本、双标和用途评审前均为待决；
不得以生成器锚点冒充人工真值，也不得把 R2 候选阈值写成 R0 实测结果。

## 9. 开发集与固定回归集划分

- **先按家族划分，再处理页。** 同一家族的各版本、相邻选页、近重复页及跨页题组进入同一 split，禁止按页随机拆分。
- R0 获准家族原则上约 **2/3 开发、1/3 固定回归**，同时保证两个集合都覆盖 408、CET、其他学科及文字/扫描/混合类型。家族数太少无法兼顾时，披露实际分层缺口，不复制家族补数。
- **开发集**用于调整分块、OCR/解析参数、提示和标注协议；每轮记录样本版本、配置和结果。参与调参的合成数据不得改称为未知真实留出集。
- **固定回归集**冻结家族、版本、请求页、真值和协议版本，只用于重复验证。变更须新建数据集版本，记录原因、审批和影响范围；不得替换失败样本或仅保留成功页。
- 正式代表性质量判断还需未参与调参的新家族留出集；当前为 0，不能宣称已具备。R2 扩样时先补独立留出家族，再按比例扩开发/回归，不能用 R2 总页数替代独立性。
- 300 页等性能材料单列 `performance`，不进入真实质量或上述学科分层分母。
