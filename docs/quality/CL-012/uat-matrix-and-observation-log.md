### 1.1 状态填写规则

- `未执行—参与者`：脚本可执行，但须先完成招募、同意和主持人安排；不得由观察者代填“通过”。
- `未执行—API`：等待对应 `planned` 端点及真实依赖实现；不得以 mock 返回或 OpenAPI 样例通过替代。
- `阻塞—原型`：当前没有对应交互或已有差异使该任务无法有效走查；关联第 6 节差异编号。
- `阻塞—契约`：预期行为或入口尚未由契约负责人确认；确认前不自行发明端点/状态。
- 实际执行后只填 `通过 / 失败 / 部分通过 / 阻塞 / 未执行`，并附不可公开敏感信息的证据引用。预期结果不是观察结果；参与者没有完成任务时如实记失败，不代做剩余步骤。
- 一条用例在桌面和移动分别记录；同一用例不能以桌面结果推断移动通过。缺陷修复后新开会话/记录，保留原失败。

### 1.2 共同准备与停止条件

1. 固定被测 commit、原型构建、浏览器与视口；建议桌面至少 1280×800，移动至少 390×844，并补一种较窄设备。记录键盘-only、缩放 200%、系统减少动态效果等实际设置，不把建议值写成实测环境。
2. P 层仅使用仓库已有 mock 内容，不让参与者提交真实私有 PDF、姓名、邮箱、访问令牌或敏感学习经历。E 层只用有明确使用权的合成 PDF 和两个隔离的合成账户/空间。
3. P 层须依据[招募与同意规则](../../research/CL-002/recruitment-and-consent.md)取得可追溯同意，说明任务、记录方式、退出权和撤回方式；拒绝录音/录屏时改用获同意的笔记。同意凭证与观察记录分库/分权保存，CSV 只放受控引用。
4. 主持人读出任务，不先讲解按钮位置；参与者可自愿边想边说。主持人只在安全、隐私或无法继续时介入，并记录介入时间和原话；观察者不得替参与者点击。
5. 出现真实敏感信息、非预期跨空间内容、取消/删除后内容复活、历史作答被改写，立即停止相应试跑、隔离证据并升级；不要为补齐记录继续操作。
6. 截图/录屏先遮盖身份、地址栏敏感参数和私有正文；公开仓库只提交去标识汇总和受控证据编号，不提交原始媒体、完整作答、导出的文件或真实请求/响应正文。

## 3. E 层：真实 API／浏览器 E2E 矩阵

以下全部是**待实现后执行的验收脚本，不是当前运行结果**。请求必须带真实服务端会话；变更请求按契约带可信 Origin、`X-CSRF-Token`、16–128 字符随机 `Idempotency-Key`，条件写操作带读取所得单个强 `If-Match`。测试 ID 使用实际不透明 UUID，不用客户端 `space_id`、哈希或 VersionRef 自证权限。

## 4. 观察重点与完成判定

### 4.1 不引导参与者的核心提问

每条 P 层任务结束后询问，不把答案先读给参与者：

1. “这份内容从哪里来？哪些部分能学，哪些不能？为什么？”
2. “刚才哪一步已经生效，哪一步只是建议或演示？”
3. “现在停止/重试/取消/删除，会影响哪些已有记录？”
4. “恢复后哪些任务延期？已完成作答有没有变化？你怎样撤销？”
5. “如果刚才没有看到你想看到的结果，你下一步会怎么做？”

有效完成不是只看最终页面。记录首次成功所需时间、错误点击、回退、主持人介入、参与者自己的解释及是否发现 mock 内容错配。登录、上传受理、浏览讲解、生成候选、打开恢复页均不能单独算有效学习证据或恢复成功；证据口径仍以 CL-001b 为准。

### 4.2 P 层通过条件

- 三条路径的指定参与者任务均有独立去标识记录；正常路径和失败/边界路径不合并成一个“通过”。
- 参与者无需观察者代操作即可说明来源、可用范围、未确认变化、历史记录及下一步；答错/失败不被界面改写成成功。
- 桌面、移动和键盘用例按实际环境分别验收；所有失败有缺陷编号、严重度、复现步骤和修复后的新记录。
- D01–D11 中与所测任务相关的阻塞项已修复或由契约/产品负责人书面缩小本论次范围；不能靠主持人解释掩盖界面矛盾。

### 4.3 E 层通过条件

- 对应端点已按[漂移与准入规则](../../api/CL-007/drift-and-admission.md)从 planned 正式准入，测试目标不是手写 OpenAPI 或 mock 服务器。
- 每条用例保存请求/资源/Job/版本的可对账引用和前后事实；权限、取消、删除、未知上游结果及恢复必须有负例，而非只验证 UI 文案。
- 合法合成资料、两个隔离账户、真实数据库/对象存储/索引/worker、受控故障注入及清理能力就绪；涉及供应商时另有已批准用途、预算、地域/留存和删除条件。
- 内容公共发布、正式诊断和外部权利/隐私/学科签审分别留证；E2E 通过不自动批准这些闸门。
