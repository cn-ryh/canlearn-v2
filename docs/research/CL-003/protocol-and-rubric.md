# 固定任务、可比条件与盲评

版本：1.0-draft · D/C 首轮前确认人及日期：待登记。
所有对象使用同一输入哈希、问题、顺序和截止日，先执行再盲评，不根据厂商表现改题。

## 固定条件

- 原生 Web 能力优先，记录浏览器版本、操作系统、地区（执行人实际确认，不推测所在地）、语言、套餐、当前配额和产品可见版本；每轮用新空间，不混入历史资料/问答。
- 初始输入仅四个 v1 PDF；v2 只在纠错阶段追加。受限文件数时按固定 D01→D04 顺序分成单文件会话，记录限制；与多文件结果分层比较，不强行合并。
- 学习时间固定为 2026-10-05 至 2026-10-11，本周剩余容量 360 分钟，统一目标截止日为 2026-10-17 20:00 UTC。若真实实测晚于该窗口，整轮预先统一平移日期并升协议版本，禁止按对象分别变动。
- 每一步观察上限建议 10 分钟；达到即记 timeout/censored，保存等待时长，不把未完成延时填为 0 或丢弃。每步最多一次原提示重试；首轮与重试分别留输出、操作数和消耗。
- 优先原生界面任务。无原生入口时可在对话中发送同一请求，但标 conversation；对话建议与持久化任务/计划能力分栏报告。无法访问不记 0 分，不推断产品无此功能。

## 指标与评分（首轮前锁定）

不生成加权综合排名；按维度和受测覆盖报告。状态为 tested / not_run / unavailable / timeout；后三种分数留空而非填 0。每条结果须有证据 ID、版本/输入 SHA 和盲评人。

| 指标 | 固定规则 |
| --- | --- |
| 引用定位 | 每个 B02 项：2=答案及版本/物理页正确且可定位对应段落/区域；1=内容正确但只有文件级依据或无法回跳；0=答案错误或引用错误。报告 2 分项/实际受测项，并列受测项/计划 7 项，不能隐藏未测 |
| 缺页识别 | 2=识别 D04 原页 41 不可用且不编造；1=只指出资料不足；0=臆造缺页或宣称全部完整。分母只含实际测试项 |
| 五题可答性 | 每道题须题型符合、能独立求解、答案合理且依据有效；计 usable/实际生成数量，同时报告 usable/要求的 20 道；少生成和多生成、重复题各记数量。双义填空/合理短答变体允许，不能机械判错 |
| 纠错 | 2=32 m、来源版本明确且已影响产物可定位/失效并保留原作答；1=新回答纠正但传播或版本能力不可确认；0=继续错误或改掉历史记录。单列算术与持久化能力，不用同一个分数推断所有功能 |
| 容量/确认 | 2=可行且逐项差异清楚，保持 T0、估时与用户确认；1=建议可行但没有持久化确认/差异；0=超过240、暗改估时/完成项或未确认执行 |
| 撤销 | 2=实际撤销计划版本并保留完成记录；1=仅有可复现人工恢复；0=尝试失败/破坏记录。未能进入原生流程记 unavailable |
| 用户/服务成本 | 点击、提交/重试、等待秒数、模型/套餐消耗及实付金额分别记；未知留空，实为零才填0，币种分开；原生与人工绕行分开 |

## 盲评与可比性

D 将截图/输出去敏为匿名 run ID，产品映射只放私下文件；评审可见相同输入、协议和输出，不见产品/套餐名称。若界面品牌不能有效遮盖，标 unblinded 并解释。C 独立检查引用和解题，分歧保留原评分，由 A 仲裁记录理由。不能只挑最好的重试。

同地区、同套餐层级、同客户端和输入模式才直接比较；配额差异、部分功能试用、结果语言、人工绕行必须显式说明。小合成集不能证明学习效果、真实复杂 PDF 质量、普遍可用性或厂商整体缺失能力。
