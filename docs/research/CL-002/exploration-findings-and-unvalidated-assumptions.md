## 2. 记录单元与证据链

### 2.1 四级记录单元

| 层级 | 最小记录单元 | 必记内容 | 分析用途 |
| --- | --- | --- | --- |
| 招募轮次 | 一次渠道/时间窗口内的邀请 | 渠道、邀请、回应、筛选、同意、完成、拒绝、缺席、退出及缺口 | 覆盖与招募偏差，不把同意数当完成数 |
| 会话 | 一个 `session_id` 下的完整或部分试访 | 主组/学科、日期、脚本版本、模式、同意与资料范围、执行人、整体结果 | 人数去重、完成状态、跨组比较 |
| 步骤尝试 | 同一步骤的一次操作；中断重试增加尝试序号 | 起止/耗时、实际行为、提示原文与次数、结果、失败点、人工回退 | 五步结果、失败与重试，不掩盖首次失败 |
| 观察事件 | 一次痛点、错误、不信任、拒绝、中断或恢复动作 | 发生阶段、去标识事实摘要、直接原因、证据 ID、后续处置 | 痛点编码、失败分类和反例核对 |

会话沿用 CL-002b 的 `completed / partial / failed / withdrawn`；步骤使用 `independent / assisted / failed / declined / unavailable`。`declined` 是有效观察，`unavailable` 是条件不足未测，二者不得改记为成功或失败操作。参与者答错与礼宾产物质量失败分开记录。

### 2.2 每场必备材料

执行人只把空白模板复制到仓库根目录的 `research-private/CL-002/` 后填写：

1. 会话模板：同意范围、脚本版本、主组、资料/夹具版本、实际模式、执行人与审核人。
2. 操作台账：五步均有记录；未做步骤也写 `unavailable` 和原因，提示、失败、拒绝、重试、中断、恢复不省略。
3. 工时成本表：准备、解析、来源核对、讲解、练习审校、计划、主持、返工、重试和追访分别记录；等待与主动工时分开。
4. 受控证据索引：只使用证据 ID 关联同意、资料许可、来源卡、原作答、计划版本和后续观察，不在公开文档放原件。

可复核引用链为：**会话与同意范围 → 资料/原创夹具版本 → 来源卡 → 讲解 → 练习及原始作答/新检验 → 技能与来源 → 原计划/提案版本 → 确认、拒绝或撤销 → 后续实际行为**。任何断链只报告已能证明的部分，不用研究者叙述补齐。

### 2.3 事实、解释与结论分栏

每条观察同时保留以下字段，避免把偏好写成行为：

| 字段 | 填写规则 |
| --- | --- |
| 证据类型 | 自述经历 / 口头偏好 / 现场行为 / 后续行为 / 研究者解释 |
| 去标识事实 | 参与者实际做了什么、在哪一步、结果如何；不写可识别原话或资料内容 |
| 操作者与帮助 | 参与者、主持人、整理/审校人；提示次数、人工动作和等待 |
| 结果与反例 | 按统一状态填写；保留拒绝、不信任、答错、失败及与预期相反的行为 |
| 证据 ID 与版本 | 指向私下受控证据；记录修正前后版本，不覆盖错误记录 |
| 研究者解释 | 单独标记为假设，不改写为参与者事实或群体结论 |

公开汇总只含去标识计数、类别、证据状态和限制，不含姓名、联系方式、原始资料、同意凭据、原始笔记、私下 CSV、签名 URL、可识别引语或罕见属性组合。

## 3. 首轮分析流程

### 3.1 单场整理与复核

1. 会后按时间顺序补齐事件链和工时，不凭印象只写最终成功结果。
2. 将自述、口头偏好、现场行为和后续行为分开编码；参与者纠正主持人复述后再定稿。
3. 核对资料许可和实际处理范围。越权、权利不明或质量不可用时停止相应处理，保留原步骤失败/未测事实。
4. 非作者复核人依据 CL-002b“可重现性检查”检查五步、证据链、失败留痕和公开边界；退回项未修正前不进入汇总。
5. 同意无效、已撤回或隐私处置未完成的会话暂停分析，按 CL-002a 隔离/删除并复核，不用其他会话冲抵。

### 3.2 跨会话编码

先按主组/具体学科和脚本版本分组，再按“近期真实流程—五步任务—恢复后续”编码。开放编码只用于归类真实记录，不预先强迫材料支持产品方案。相同动作可有一个主码和必要辅码，但汇总时须按会话去重，避免同一场反复提示被算成多个独立痛点。

建议初始编码维度如下，可在保留原始码和版本说明的前提下增补：

- **痛点阶段：**找资料、选范围、定位依据、判断可信度、理解/作答、核对反馈、安排容量、选择恢复、实际继续。
- **障碍类型：**找不到、看不懂、无法核对、不信任、操作负担、时间/容量冲突、资料权利、资料质量、人工依赖、其他。
- **应对方式：**原有工具/人工方法、独立解决、提示后解决、放弃、改用原创夹具、保留原计划、中断或退出。
- **证据强度：**自述单次、现场单次、跨会话重复、后续可复核行为；强度不等于统计显著性或产品效果。
- **反例：**原流程已足够、无需提案、拒绝展示/操作、喜欢但未行动、人工方案反而增加工作。

“重复痛点”暂定义为**同一主码出现在至少两个不同真实会话，且各自有可定位事件记录**；这是首轮整理规则，不是总体频率。只有一场时写“个别观察”，只有口头意愿时写“口头反馈”，不能合并成已验证需求。报告同时给出出现会话数、该步骤实际被测会话数和反例数；分母为 0 时不计算比例。

## 5. 失败案例分类、严重度与处置

### 5.1 分类记录表

每个失败事件至少记录：事件 ID、会话 ID、步骤与尝试序号、发生时间、主类/子类、严重度、参与者实际行为、直接原因、提示与人工投入、输入/输出版本、回退、是否恢复、未测后续、证据 ID。一个事件只指定一个主类，可附辅类；跨步骤连锁失败分别留事件，避免只记最后一步。

| 主类 | 子类示例 | 判定与汇总规则 | 必须保留的处置 |
| --- | --- | --- | --- |
| F1 招募/同意 | 不符合筛选、拒绝、缺席、必需同意无效、撤回 | 招募未完成与操作失败分开；退出从相应分析剔除 | 停止联系/采集，去标识计数及退出处置日志 |
| F2 资料权利 | 权利不明、许可范围不足、拒绝展示、疑似越权或第三方未授权 | 同意展示不等于复制、训练或发布许可；换夹具后原路径仍未验证 | 停止复制/外传，必要时隔离并交权利责任人 |
| F3 资料质量/输入 | 损坏、加密、缺页、扫描/识别错误、格式复杂、范围部分可用 | 区分失败、部分可用和未测；部分可用不写成全成功 | 保留版本与可用范围、人工整理和等待、回退记录 |
| F4 查证/信任 | 错引、无来源、原文不支持、来源不可访问、过度推断、参与者不信任 | 参与者答错定位与礼宾引用错误分开；反例不得删除 | 保留错误与修正版本、质疑依据和中断情况 |
| F5 练习/学科质量 | 题目歧义或错误、答案泄露、代答、评分不可信、题目提前曝光 | 学习答错可为有效观察；礼宾质量失败不计有效学习证据 | 原作答、审校状态、帮助程度、重做尝试和未测范围 |
| F6 计划容量/版本 | 容量不可行、估时争议、已完成任务误排、锁定冲突、版本冲突 | 不压缩估时或改写历史；拒绝削减不是操作失败 | 回到已确认原计划，记录冲突和不可行范围 |
| F7 提案/撤销/恢复 | 提案生成失败、不能理解影响、拒绝、未确认改计划、撤销失败、后续未继续 | 拒绝是有效观察；接受、确认、撤销和实际继续分别汇总 | 原计划是否保持、人工回退、后续窗口与证据或“未观察” |
| F8 会话中断/执行 | 超时、设备问题、主持人偏离、步骤遗漏、中断、重试失败 | 同会话增加尝试序号；未做步骤为 unavailable，不另起成功会话 | 中断点、已保存内容、恢复点、提示及额外人工投入 |
| F9 隐私/数据事件 | 超范围收集、私有信息误发、公开泄露、撤回未执行 | 不计为普通可用性失败；暂停相关分析与发布 | 立即停止传播、隔离/删除、通知负责人并记录复核状态 |
| F10 成本/证据完整性 | 工时漏记、证据断链、来源/版本缺失、复核退回 | 证据不完整时只报告可证明部分，不补造记录 | 缺口、责任人、退回原因和修正版本 |

### 5.2 严重度与报告门槛

严重度描述处置优先级，不是发生概率或产品上线评级。首轮任何严重度事件都进入私下台账；公开只发布经审核的去标识汇总。

| 级别 | 操作定义 | 处置和公开门槛 |
| --- | --- | --- |
| S0 阻断 | 同意/权利无效、隐私泄露、撤回未执行、危险或明显越权处理 | 立即停止相关会话和分析；完成数据/权利复核前不得恢复。公开只报事件类别、状态和未决风险，不复制敏感内容 |
| S1 严重 | 结果不可采信或核心路径无法继续，如错引/题目错误进入产物、未确认改计划、证据链关键断裂 | 对应结果不得计成功；记录回退、修正版本和受影响范围。首场即须报告，不等待“重复出现” |
| S2 一般 | 经提示、重试或人工回退可继续的操作/质量问题 | 保留首次失败和增加工时，按主类汇总会话数与尝试数 |
| S3 观察 | 未造成任务失败但值得后续核实的困惑、轻微偏离或额外负担 | 作为脚本修订线索，不升级为痛点或缺陷结论，除非后续证据支持 |

**汇总门槛：**S0/S1 单场即列；S2/S3 一场列个别观察，至少两个不同会话才可使用“重复”标签。任一类别为 0 次真实观察只能写“未观察到”，不能写“不存在”。组间或学科间比较必须同时披露样本数、被测步骤、脚本版本和未测项，不依据少量案例排名。

## 6. 恢复、成本与招募的专项判定

### 6.1 恢复不接受单一度量

按以下互斥又连续的状态记录：查看提案 → 修改/明确确认/拒绝 → 是否执行撤销 → 是否实际继续任务。拒绝提案和保留原计划是有效结果；确认不等于恢复，未获得后续观察证据写“未观察”，不能写“恢复成功”或“恢复失败”。建议的约 72 小时窗口只有在后续联系同意有效时执行，实际窗口、任务和证据 ID 必须公开口径一致。

首轮只回答：参与者能否理解取舍、是否接受/拒绝及原因、人工撤销是否可行、是否出现可复核继续行为。不能据此宣称长期留存、学习效果或自动恢复能力。

### 6.2 成本不作无分母估算

按会话、角色、活动、尝试汇总主动工时；等待另列，实付费用按币种分列，未知留空。失败准备、审校返工和重试均计入。若计算每有效礼宾单元成本，先定义有效单元、给出非零分母及包含的活动范围；分母为 0 时不计算。折算人工成本另列费率和假设，不当作实付。

### 6.3 招募偏差与下一轮计划规则

每轮按 CL-002a 公开目标/实际/缺口和渠道计数，披露熟人转介、社群自选、设备、时间窗口、拒绝/缺席/退出等偏差。首轮如某组没有真实完成者，明确标记缺口，不能用内部演练、跨组重复或其他学科人数冲抵。

若某组或学科连续两轮无合格完成者，按 CL-002a 标记招募阻断，尝试教师/学生组织转介、不同学习社群、不同时间段或经批准的公开报名页。当前尚无真实轮次，因此具体下一轮渠道、负责人和日期均为待真实执行人登记，不虚构招募成效。

## 7. 首轮结论与验收边界

真实记录到齐后，结论只能按以下结构形成：

1. **证据范围：**研究日期、实际执行/审核人、脚本版本、模式、各组/学科人数及退出排除。
2. **探索观察：**重复痛点和个别观察分别列计数、证据类型、反例；没有证据则保留空白/缺口。
3. **成功与失败：**五步状态、失败分类、严重度、权利/质量问题和回退；失败不能只附成功案例之后作脚注。
4. **恢复与成本：**接受/拒绝/撤销和后续实际行为分列；主动工时、等待、重试、实付成本及分母完整。
5. **假设处置：**逐项说明初步支持、反例或证据不足，列出下一轮需修订的脚本、招募和审校事项。
6. **审核：**A 非作者审核人、验收人及必要的外部权利/学科签审真实登记，不可由作者自签。
