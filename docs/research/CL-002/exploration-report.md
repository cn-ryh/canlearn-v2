- 工时成本：人力按角色活动汇总 `active_minutes`；等待另计；货币按币种分别汇总，未知不填 0，重试计入。若计算每有效礼宾单元成本，明确有效单元数，分母为 0 时不计算。估算人工成本须另列工资假设，不把它当实付。
- 未验证假设、下一轮招募渠道、预计补齐的组/学科、负责人和下一检查时间：待填。
- A 审核结论：继续探索 / 修订脚本 / 缩小研究操作范围 / 暂停；不得未经范围变更评审更改已确认的完整 P0 目标。
