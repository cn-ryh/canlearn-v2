## 招募筛选规则

### 通用纳入、排除与分组

**同时满足以下条件才可纳入：**

1. 年满 18 周岁，能独立作出参与决定；初期不招募未成年人。
2. 当前或近六个月有真实、持续的自主学习目标，能说明所用资料、工具及最近一次学习中断或资料处理困难。
3. 自愿参加约 45–60 分钟访谈及人工辅助体验，理解可拒答、跳过任务或退出。
4. 能使用本人有权使用的资料，或接受不展示文件、改用合法原创夹具。资料操作未实测时单列，不伪装成已验证路径。

**出现以下任一情况不纳入或停止会话：**无法有效同意；仅对产品、课程销售或 AI 技术感兴趣而没有对应学习目标；要求提供账号密码、完整付费资料、他人隐私或敏感信息；资料来源/许可明显违法或权利无法判断且仍要求复制外传；访谈涉及需要专业执业判断的高风险决策。无需偏好 AI、熟悉软件或承诺购买，不以成绩高低作为筛选门槛。

每人只指定一个主组，以筛选时投入时间最多的当前主目标为准；其他目标记为次要背景，跨组人数去重。主组改变时保留历史记录并说明原因，不能为填补缺口静默换组。记录准备阶段、资料来源、工具熟练度、设备、是否经历中断及招募渠道，用于披露自选偏差。

### 408 组

- **目标人群：**正在或近六个月准备计算机学科专业基础综合（408）的成人自主学习者。
- **必须确认：**目标考试/阶段；数据结构、计算机组成原理、操作系统、计算机网络中的当前重点；最近使用的教材、课程、题库或笔记；一次真实的资料查找、错题处理或中断经历。
- **覆盖建议：**入门、系统复习、冲刺/复盘均有参与者；覆盖不同资料来源、跨考/本专业背景、自学与课程辅助、是否中断。上述是偏差观察维度，不要求人人学完全部四科。
- **分组边界：**只学习计算机课程但没有 408 目标者，不并入 408；可进入其他学科并标明具体学科。
- **筛选问题：**“你目前最接近哪个准备阶段？最近两周主要学哪一科、用什么资料？请描述一次找不到依据、做错题后无法核对，或学习被打断的经历。”

### 四六级（CET）组

- **目标人群：**正在或近六个月准备大学英语四级或六级的成人自主学习者。
- **必须确认：**主目标为四级还是六级、当前准备阶段、常用词汇/阅读/写作/翻译等资料，以及一次练习核对或中断经历。主目标只能选一个，同时准备者在次要背景中记录另一项。
- **覆盖建议：**四级、六级各约 6 人；覆盖首次准备与再次准备、不同英语基础和不同工具使用程度。实际比例必须公开，不将建议配额写成实际构成。
- **研究边界：**本阶段以文本资料、阅读、写作、翻译和练习流程为主；当前无合法音频及相应评测时，不借访谈宣称产品已支持听力或口语。
- **筛选问题：**“你的主目标是四级还是六级？最近一次做练习怎样核对答案和回到资料？哪一步最容易让你停下来？”

### 其他学科组：至少数学、物理、化学

- **目标人群：**以数学、物理或化学为当前主目标的成人自主学习者，使用自己有权使用的教材、讲义、题目或笔记；平台没有对应公共库也可参与。
- **必须确认：**具体学科和课程/主题、当前学习目标、资料类型、最近一道题或一个概念的核对过程、一次中断。不能只填“理工科”或“其他”。
- **覆盖要求：**整体至少覆盖**数学、物理、化学三个独立学科**，建议各约 4 人。新增学科另列，不用于替代这三个学科中的缺口。
- **分组边界：**以数学为主的 408 考生仍按主要学习投入归组，不能同时计入数学；以物理/化学为职业工作而非当前学习目标者不纳入对应样本。
- **安全与质量：**只讨论资料组织、查证、练习和恢复，不要求上传危险实验数据，不提供实验操作、医疗、工程或其他专业执业判断。
- **筛选问题：**“请说出一个具体课程或主题。你最近用什么资料学习？遇到公式、题目或概念不理解时如何核对？请展示流程而非提供完整资料。”

### 私下筛选记录

为每位候选人分配 `participant_id`，仅记录主组、学科/级别、渠道、筛选结果和必要背景。姓名、电话、社交账号等只存于经批准的私下联系映射，不写入本包、Git 或公开 Issue。拒绝参与、未到场和退出也保留去标识计数及原因类别，避免只报告成功者。

## 招募渠道、联系规则与偏差

| 渠道 | 联系办法 | 重点覆盖 | 必须披露的偏差 |
| --- | --- | --- | --- |
| 课程/备考社群 | 经管理员同意发布统一邀请，不抓取群成员信息 | 408、四六级、课程学习者 | 群内活跃者、自学者与报班者比例可能失衡 |
| 教师/学生组织转介 | 由转介人转发邀请，潜在参与者主动联系研究团队 | 数学、物理、化学 | 成绩、师生关系及自愿性偏差；教师不得提供学生名单 |
| 成人学习社群 | 在允许研究招募的社区发布，经社区规则审核 | 在职、自学、中断后恢复者 | 数字工具熟练和自主报名偏差 |
| 团队个人网络 | 只发送邀请，不由上级或利益关系人施压 | 首轮脚本试访 | 熟人、礼貌性正反馈和相似背景偏差 |

联系时使用同一邀请文本，先确认是否愿意接收筛选说明，再安排时间。首次邀请后至多提醒一次；明确拒绝、要求停止联系或两次未回复后停止。不得以成绩、教师评价、课程资格或持续服务为参与条件。补偿金额、方式、未完成会话如何处理和预算如有，须在邀请前由执行人写明，不自行承诺支付。

每次招募轮次记录渠道、邀请数、回复数、筛选通过数、同意数、完成数、拒绝/未到场数、缺口和设备/熟人/时间窗口等偏差。若某组或学科连续两轮无合格完成者，将该覆盖标为**阻断**，不得用其他组人数冲抵；暂停无效应答分析，改试教师/学生组织转介、不同学习社群、不同时间段或经批准的公开报名页。仍不足则保留缺口，只报告已覆盖范围。

## 联系、安排与退出流程

### 正常联系与会前确认

1. **邀请：**通过已登记渠道发送邀请，不先收集资料。回复者获得私下筛选问题和研究说明。
2. **筛选：**执行人记录纳入/排除及主组；排除者只保留必要去标识计数，不继续联系。
3. **同意前核对：**安排前填好联系人、时间、访问者、保存/保留/删除和第三方处理安排；参与者阅读后分别选择访谈、资料、录制、后续联系。
4. **安排：**只在私下映射中保存联系方式和日历信息，向参与者确认时间、时长、取消方式及无需提前发送完整资料。
5. **开始前复核：**执行人再次说明自愿、拒答和退出权，确认同意版本未变化；有变化则重新取得同意。
6. **会后：**按选择决定是否追访，更新会话状态和可复核证据引用。`received_evidence` 指已收到可复核记录，不是口头约定。

### 退出申请与执行

1. **接收：**参与者可通过研究说明中的任一有效联系渠道提出“停止联系”“退出后续访谈”或“撤回并删除可撤回数据”，无需说明理由。实际联系人：**待填写**；预计确认时限：**待填写**。
2. **确认范围：**只核对会话编号及必要身份映射，不额外索取无关信息。身份无法确认时采用已审核的最低验证办法，防止误删他人记录。
3. **立即停止：**状态改为 `withdrawn`，停止后续联系、采集和新的分析使用；同时取消尚未执行的追访、第三方处理和公开引用安排。
4. **删除与隔离：**按说明删除/返还资料原件、笔记、录制和联系映射，处理备份及已发送副本，并记录执行人、日期、范围和无法删除的原因。尚未过保留期且依法必须保留的项目须单独隔离、限制访问并告知依据；不得借“备份”继续分析。
5. **已完成汇总：**不可逆匿名汇总按事前说明处理；仍可关联到会话编号的内容不得视作匿名，须删除或排除。
6. **反馈与台账：**向申请人确认处理结果及任何限制，保留去标识的退出计数和处理日志。退出后的记录从相应分析中剔除，在汇总中说明排除数；公开台账不记录退出原因原文、姓名或联系方式。

若参与者仅拒绝录音、资料展示或追访，不自动视为退出整场访谈，按分项选择继续其余部分。发现私有信息误进 Git、公开 Issue 或非授权渠道时，立即停止传播、通知数据/权利负责人并按事件流程处置；公开讨论只保留事件和修复状态，不复制泄露内容。

## 台账模板与更新规则

### 私下明细

`templates/recruitment.csv` 每行一个真实候选人，主组唯一。将空白模板复制到仓库根目录的 `research-private/CL-002/` 后填写；联系方式使用单独的私下映射，不在 CSV 增加姓名或联系方式列。

- `primary_group`：`408` / `CET` / `other`；`subject` 对 CET 填 `CET`，对其他组填数学、物理、化学等具体学科。
- `screening_status`：`pending` / `eligible` / `ineligible`；未筛选不能写成合格。
- `consent_status`：`not_requested` / `pending` / `consented` / `partial` / `declined` / `withdrawn`。`partial` 表示只同意部分可选项；访谈必需项未同意时不得安排。
- `material_permission_status`：`not_requested` / `not_provided` / `verified_limited` / `unverified` / `declined` / `withdrawn`。`verified_limited` 必须有私下许可范围和依据，不等于公共发布权。
- `followup_consent`：`yes` / `no` / `withdrawn`；不得用访谈同意替代追访同意。
- `status`：`invited` / `screened` / `consented` / `scheduled` / `completed` / `declined` / `withdrawn` / `no_show`。
- `received_evidence`：只填 `yes` / `no` 和受控证据编号（如需编号另建受控字段），证据原件不进入 Git；`updated_at` 使用实际更新日期。
- `exclusion_reason` 使用预设类别，如年龄不符、无对应目标、无法同意、资料权利未验证、退出；避免写入可识别自由文本。

### 公开汇总

`templates/recruitment-summary.csv` 是空白/初始汇总模板。每轮按主组和数学/物理/化学明细分别统计目标、已同意、已完成、合法可用资料数和缺口；CET 另在报告中拆四级/六级。汇总公式为 `gap = target - completed`，不小于零；超额完成时另报实际数，不用负数缺口掩盖其他组不足。

目标进度分别报告已联系、同意、完成和有合法可用资料的会话数。分母、去重办法、退出排除数和统计日期必须一致；不得把同意人数当作访谈完成数，也不把资料许可人数当作完成数。公开 Issue 只链接汇总和未决风险，不粘贴私下明细。
