# CL-009b · 逐页与引用真值协议

2026-10-13 · C制定、B复核待完成；没有填写真人双标记录。

## 标注单位与状态

锁定source_version＋sha256＋请求页清单，PDF页序从1计，印刷页码独立记录。
每个请求页必须有记录：success、blank、failed、missing、不支持类型分别记录，不把blank当失败，
不把failed/missing删出分母。复杂页留原件区域、失败原因和可用子范围。

每页标文字区域、阅读顺序、公式、表格/题组和引用锚点。区域坐标明确页宽高/旋转与
左上原点规范化[0,1]bbox；引用绑定文档版本/页/区域/文本span，不能只标视觉页码。
跨页题组记录group_id与全部成员页；漏页、旧版和撤回状态独立于解析质量。

## 指标与判定

| 指标 | 真值/计算口径 | 失败与边界 |
| --- | --- | --- |
| 页覆盖 | 每个请求页是否有明确状态、是否产出预期锚点；报成功/空白/失败/缺失数 | L300锚点覆盖仅烟测，不证明正文/公式正确 |
| 文本CER | NFC规范化后按Unicode码点做编辑距离(reference,hypothesis)/reference长度；默认保留标点/大小写/数字，空白策略固定版本 | reference空时不除零；空白页误产出文字单列。繁简/公式不自动替换；宏/微平均及各学科分别报 |
| 阅读顺序 | 区域ID先后偏序与解析顺序的违例对数/可比较对数 | 不可比较对不计；不能只用“正文存在”代替双栏顺序 |
| 公式合格 | 数字、变量、上下标、符号/运算结构、单位逐项；文本与渲染双方能回查 | 图像公式与OCR公式区分；语义错误/漏项判不合格，不仅比LaTeX字符串 |
| 表格/题组合格 | 行列/合并单元格、标题/单位、单元文本与题号/子问对应 | 缺行/错配/跨页断裂单列；复杂表格不支持要显示 |
| 引用回跳 | 锁source版本、PDF页、区域，人工确认内容支持题目/讲解；来源集合必要且不越域 | 旧版、越域、撤回、伪造编号、非支持证据分别失败 |
| 无答案/干扰 | 标明问题及缺失证据/冲突来源，允许输出insufficient_evidence | 拒答阈值不从当前小样本冻结；不把低相似度直接当无答案真值 |

原始真值保留，规范化结果带protocol_version。正式阈值按实际样本和用途决定，
R2候选阈值不能写成实测质量。覆盖分母按全部请求页，正文CER按有参考文字的页并同时报告不适用数。

首次用同一份2页样例走通差异/仲裁后锁协议，再扩样；协议变更触发受影响页复标。
