## 证据与认证回归

旧探针源码只在临时目录，摘要无法重建源码；其九组观察仅作历史兼容性材料，
不作可复现安全回归。此次不重写源码冒充原探针，也不把内存状态模拟当 Better Auth 验证。
选择由 CL-101 在正式接入前交付可维护的真实 HTTP/数据库回归替换：固定库版本、
锁文件、迁移、合成账户生成器、运行命令、原始断言/结果和源码摘要随仓库交付，公共 CI 不依赖 SES。

C 验收至少覆盖：所有原生 sign-up/别名/OAuth 注册路径不可绕过邀请；一码并发消费；
账户/邀请/通知意图任一提交失败全部回滚；验证及找回过期、重放、并发回调；
重发后的旧令牌失效；已删除/撤销账户晚到回调不能复活；找回成功后全部旧会话及缓存失效；
退出、管理员撤销、多实例、连接池复用、Origin/CSRF、限流、枚举响应与日志脱敏。
普通验证重放可返回统一幂等响应，但不得创建新会话或重复改变安全状态。
邀请仍不绑定邮箱，一码一次七天，成功注册即消费；验证一小时、找回三十分钟沿用已确认值。

## 注册与邮件交付

API 唯一注册入口在同一 PostgreSQL 事务内锁定/条件消费邀请码、创建未验证账户、
持久化一次性验证记录及 NotificationOutbox；任一失败全回滚。禁止在事务内调用 SES。
验证记录仅存令牌摘要；Outbox 所需链接密文独立加密、限权、短期保存，不能进日志或 Temporal history。
若固定认证库不能与这些记录共享事务，CL-101 必须先补适配并证明回滚，不能先发邮件再补账。

提交后 dispatcher 领取已提交通知并限流发送；语义为至少一次交付，不能声称邮件恰好一次。
幂等键为账户＋用途＋令牌代＋模板版本。SES 成功但 ACK/本地记录丢失可能重复邮件；
保留 delivery_unknown，若供应商支持先查询原请求，无法确认则在重试额度内可重复交付同一有效链接，
不创建新账户或自动消费新邀请。发送失败账户仍未验证；用户可在限流后请求重发。
重发在事务内递增令牌代并撤销旧代，dispatcher 发送前重查代/状态，晚到邮件不具授权效果。
回调独立检查用途、摘要、有效期、当前代、账户状态及一次性消费，原子变更；不能只信邮件发送记录。
找回确认与会话撤销须同事务推进账户 session_epoch；所有读取入口检查该 epoch，缓存不得延迟撤销。

候选重试：最多五次发送尝试、指数退避加抖动、验证一小时/找回三十分钟截止优先；
超限进入人工可见失败，过期不再发送。重发候选每账户每用途六十秒一次、每小时五次，另设 IP/全局预算；
A 在 CL-101 启用前批准限额，C 验限流与故障注入，SES 配额不能替代应用限额。

## 真实 COS 合成验收矩阵

尚无可用私有配置及专用桶证据，本轮没有访问 COS。B 在 CL-103/104/110/117 节点用专用私有测试桶、
最小权限测试身份和原创合成文件执行，C 复核；不把 SDK 方法存在作为通过。
只清理本次随机前缀，不操作已有资料；凭据从本机私有配置读取，报告不含密钥/签名 URL。

| 场景 | 必留证据与通过条件 |
| --- | --- |
| 私有与 IAM | 匿名 GET/HEAD/Range 拒绝；限定前缀身份越前缀/越桶/列举拒绝；实际桶策略/ACL/加密脱敏快照 |
| 业务授权 | 两个合成账户同哈希仍隔离；跨账户、错版本、用途不符、撤销会话由真实 API 拒绝且不发 COS 读取 |
| 版本 | 写入两个不同载荷取得两个 VersionId，各自精确读取 SHA；不存在版本失败，不回退 latest |
| 删除 | API 提交墓碑后新的 GET/HEAD/Range/导出拒绝；直接受限对象读取的权限边界另测；delete marker 后枚举并清理所有历史版本 |
| 清理 | 原件、派生、临时对象、未完成分片和历史版本清单归零；故障后续跑幂等，独立备份按保留期跟踪 |
| 恢复 | 旧数据库/对象备份恢复到隔离环境，补最新删除与授权日志；删源不可读且不可重建发布，缺日志禁止开放 |

每条记录时间、配置摘要、随机对象前缀、版本/请求 ID、HTTP 状态、断言与清理结果；
报告与执行脚本随仓库归档，真实桶名等私有环境映射保留在受控配置。失败必须保留，不写成通过。

## 代理与用户承诺

API 对每个新请求重新授权，私有响应使用 Cache-Control: private, no-store，禁止共享 CDN；
不得向浏览器暴露长期存储密钥或可绕过撤销的对象链接。已经下载/缓存的字节无法追回，
no-store 也不保证擦除已存在的浏览器副本。在途连接应订阅撤销并尽快中断，但已发字节不可撤回；
中断延迟/在途残余量在压力测试后再承诺。备份可在批准期限内残留且隔离，恢复前重放删除。

CL-104/110 的合成容量矩阵候选为 1/20/100MiB、1/2/4 条流、整文件/单 Range/非法或多 Range、
慢客户端、客户端断开、上游超时和删除中断；100MiB 只是压力档，不是批准上传额度。
固定最大内存缓冲、连接/流数量、空闲/总截止及 Range 策略后再测南京混合负载，禁止全文件入内存。
A 在试点前按实测确定最大文件和并发；C 报吞吐、P95、RSS、CPU、超时、实际收发字节。
月成本按 API 公网出流量、COS 请求/读取/存储/版本与跨地域流量乘实际价格估算；
200M 只表示带宽上限，不能推导免费流量或月成本。没有配置/费用/负载证据不开放真实资料。
