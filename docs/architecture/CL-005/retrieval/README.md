## 输入与建议

用户接受按 10 人以内、每人5份、每份20–100页测算，另加一份300页样本。
这些是测算场景，不是上传额度、实际已接收数据或强制成功指标。
总体约50份、1,000–5,000页，再单列300页观察。分块密度建议先比较每页2–10块，
仅用于估算2,000–50,000块，真实块数取决于解析和语义结构，不以页数替代测量。

建议复用 PostgreSQL 17，在正式数据镜像中安装固定 pgvector 版本，再验证迁移/备份与 Temporal 存储兼容。
本轮用 pgvector 0.8.7 隔离镜像验证；**尚未替换主 Compose PostgreSQL 镜像**。
默认 postgres:17-alpine 没有因此自动获得扩展，不能直接在主库执行 CREATE EXTENSION 并假定成功。
先授权过滤后精确搜索；达到实测瓶颈再比较 HNSW 和迭代扫描/分区，不默认建近似索引。

词法候选采用 worker/服务侧固定分词器生成可重建词法输入，PostgreSQL 存 GIN/tsvector。
本轮比较 jieba 0.42.1＋simple；一个样例命中不证明中文检索总体合格，
英语、公式、术语和停止词/同义查询需专项评测。jieba 为候选，正式依赖尚未选定。
词法与稠密向量候选都须基于可访问、当前、已确认且用途允许的资源，
融合可先比较 Reciprocal Rank Fusion，参数及召回阈值须后续预先登记，不因排序放宽权限。

执行真实模型烟测，模型文件SHA及结果见 [embedding-results.json](embedding-results.json)。

BGE-M3 的1024维 float32 向量本体约4104字节/块，
2,000–50,000块约7.8–195.7 MiB；这是向量本体估算，未含行/元数据、词法索引、WAL、
备份及 HNSW，不能据此承诺8G数据库容量。计算依据 pgvector 的 `4 × dimensions + 8`。
E5-small 的384维本体1544字节/块，约2.9–73.6 MiB，其较小体积不保证同等质量。
