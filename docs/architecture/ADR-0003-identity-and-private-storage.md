# ADR-0003：身份与私有对象访问

- 状态：登录/邀请码/SES 方案已确认；Better Auth 1.7.7 隔离兼容性通过，正式接入及 COS/SES 能力待核验
- 日期：2026-10-12
- 对应：CL-005a / #26；A（任宇航）主责、B 复核
- 决策上下文：[CL-005 入口](CL-005/README.md)、[CL-004 权限](../security/CL-004/permissions-and-content-rights.md)

## 问题与候选

额外预算 ¥300/月且当前没有邮件服务；用户已确认现有云存储为腾讯云 COS 南京。
身份验证不能替代逐资源授权，私有原件、版本及派生资产均需可撤销访问。
用户已确认：10 人以内内部测试，邮箱注册且邀请码必填，接邮件服务并在注册后验证邮箱。
建议的邮箱/密码登录与验证后开放资料空间已获用户接受；用户选择腾讯云 SES，企业资质已有，服务与发件域名配置待完成。
Better Auth 1.7.7 已完成隔离兼容性核验，推荐作为正式接入候选，见 [验证记录](CL-005/validation-record.md)。

| 候选 | 收益 | 成本/限制 |
| --- | --- | --- |
| 受邀注册＋用户名/密码，成熟认证组件与服务端会话 | 无邮件发送依赖即可比较核心登录；便于 API 撤销会话 | 密码保护、账户恢复、邀请及限流仍需实现；组件可能要求邮箱字段 |
| 邮箱验证/验证码/找回 | 联系与恢复路径清晰 | 需补邮件发送服务并核验送达、费用、滥用控制；当前未具备 |
| 既有 OIDC/第三方登录 | 可减少部分凭据维护 | 用户尚未指定服务；可访问性、账号映射、审核、地域与退出条件要核验 |
| 自托管独立身份服务 | 标准化联邦能力 | 增加独立服务与运维，需求不足时优先级低 |

建议优先核验 Better Auth，其官方文档提供邮箱/密码、邮件验证、Fastify 集成与 Drizzle adapter；
当前 NestJS/Fastify/Drizzle 组合及邀请码事务原型已用 1.7.7 验证，推荐固定该候选后由 CL-007/101 正式接入。
原型不替代迁移、多实例、邮件发送/回滚和真实业务权限验证。不自行设计密码学或会话协议。
其 username 插件以 email/password 体系为基础，必须核实注册必填字段；不能用捏造邮箱绕过组件约束。
若收集邮箱而不验证，应明确其未验证状态，不能据此发送敏感数据或授权账户恢复。

## 推荐提案

按用户确认采用邮箱/密码＋必填邀请码＋邮箱验证作为功能需求，优先比较成熟组件，API 管理认证及服务端可撤销会话。
Web 通过同源受控入口访问 API，浏览器会话采用 HttpOnly/Secure 与适当 SameSite 策略，
状态变更接口实施 CSRF/Origin 检查；会话、密码重置和资源授权分别验证。
密码采用经维护组件提供的安全哈希与参数，不明文存储；注册、登录、邀请及恢复限流。

用户最终确认：**邀请码不绑定邮箱，任意邮箱可使用一个有效且未使用的邀请码注册，一码一次、7 天有效。**
此前“绑定受邀邮箱”的建议已被用户修正，不作为实现要求。
邀请码在服务端注册入口校验，不能仅在前端表单必填。邀请码消费与新账户创建必须原子协调，
并发抢用仅一个成功；失败注册不消费，成功注册即消费，不等待邮箱验证后才占用。
邀请码过期限制新注册，不追溯取消已成功注册账户的验证资格；已撤销/删除账户另行阻断回调。
原始邀请码不作为用户字段或日志保存，存储校验摘要及使用/到期/撤销元数据；管理员可撤销未用码，
错填邮箱或失败邮件需要受控处理，不自动将已使用码恢复为未用。
未验证邮箱仅允许必要的验证/重发/退出操作，不开放资料空间、存储或模型任务。
验证回调重复/晚到时检查已登记注册准入及当前账户状态，不重复消费邀请码；撤销/删除账户不因回调恢复访问。
认证库的原生 sign-up、其他注册路径和未来 OAuth 不能绕过邀请码；组件 hook/事务能力须实测。

用户已选择腾讯云 SES，开通、发件域名/地址验证与发送配置尚待完成。核验所选产品的地域可用性、
域名验证、SPF/DKIM/DMARC、限额、价格与送达；不从已有域名推定已开通发送能力。
用户提供站点 `cl.hangxiaonet.com`（已备案且可配置 DNS），发件域名 `no-reply.hangxiaonet.com`，
完整地址 `canlearn@no-reply.hangxiaonet.com`。已按用户要求制作 [验证与找回模板](CL-005/email-templates/README.md)，
生成本地 SES 创建请求体；用户随后报告模板已审核，验证 ID 224682、找回 ID 224683 已登记，地域/审核版本待补，未验证真实发送。
发送失败时保持未验证、可安全重试，不自动标记通过。邮件验证/密码找回令牌短期一次性、
受控存储且不进日志；用户确认验证链接 **1 小时**、找回链接 **30 分钟**，允许限流后重发。
邮件链接走可信域名，重发/恢复/登录限流并避免账户枚举。
账户恢复须撤销旧会话并审计，不由支持人员直接取得私有资料读权。上述令牌期限已确认，
会话/审计/未验证账户等其他期限仍由 Q02 在相应节点决定。

存储建议复用南京 COS 私有桶，优先比较 COS 原生 SDK 的能力及成本，再比较 S3 兼容访问，
不从“S3 兼容”推定版本删除、生命周期、加密或撤销语义完全一致。
前端上传/下载先经 API；API 流式处理与必要 Range 请求避免全文件内存缓存。
worker 使用限 Job/资源/用途的内部授权，不将长期存储密钥或直链交给浏览器。
读取、下载、导出领取前重查资源归属、用途、具体版本及删除状态；私有响应不进入共享 CDN 缓存。

对象路径绑定稳定资源及版本，文件哈希不授予所有权。开启对象版本功能时，删除闭包需要枚举历史版本，
delete marker 不等于所有版本已物理清除；备份副本与供应商副本分别跟踪。
API 受控读取便于拒绝删除后的新请求，但不能追回用户已下载字节，
在途流、浏览器副本及缓存清除须给出范围和实测证据，不只靠代理名称作保证。

## 失败、验证与退出

- 验证跨用户猜 ID、同哈希、失效会话、CSRF、错误版本、删后 Range/下载/导出及在途访问。
- 认证或存储不可用时拒绝私有读取，不能回退公开桶或放宽授权；可观测性只记最小元数据。
- 迁移认证时保持业务 user ID 与外部 identity 分离；不可迁移密码时走安全重设，并撤销旧会话。
- 迁移存储先登记清单、逐对象校验哈希/版本/权限，在验证新读取和删后拒绝后切换，追踪旧副本清理。
- 删除后的资源不因回滚重新可读；回滚需应用最新删除台账，不恢复旧凭据。
