# ADR-0005：模型网关与供应商处理边界

- 状态：提议；现有供应商/模型、价格、地域和处理条件待确认
- 日期：2026-10-12
- 对应：CL-005c / #28；A（任宇航）主责、C 复核，外部责任人按用途核验
- 决策上下文：[CL-005 入口](CL-005/README.md)、[CL-004 权利矩阵](../security/CL-004/permissions-and-content-rights.md)

## 问题与候选

用户已有聚合模型平台，提供 deepseek-v4.1-flash、glm-5.3 与 gpt 系列等别名；额外预算 ¥300/月。
用户表示平台无公开文档，兼容 OpenAI Responses 格式；平台名称、实际上游、路由和固定模型版本仍未明确，
不推定这些别名等于官方模型 ID，也不推定平台采用上游官方数据政策。
必须计入生成、独立求解/校验、修复、embedding、失败重试和在途消耗，不能只算一次主生成。

| 候选 | 收益 | 成本/限制 |
| --- | --- | --- |
| 复用现有聚合 API，按任务路由 | 接入面较少，便于用合成任务比较质量和成本 | 聚合平台及其上游都需核验，可能存在额外转发/日志与不明路由；现有账号不证明真实资料已准入 |
| 核验官方直连 API 作为候选 | 可减少聚合平台这一处理环节，路由和条款可能更明确 | 需独立核验账号、地域、价格、可访问性及资料用途，不能自动认为可用或成本更低 |
| 多供应商初始路由 | 可比较质量、价格与可用性 | 审批、适配、测试和成本对账增加；故障转移必须逐供应商获准 |
| 4070 部署本地生成模型 | 某些路径可减少外发和 API 费用 | 与 MinerU/embedding 争用资源，质量、延迟、权重许可及运维未测；不默认可替代独立校验 |

## 推荐提案

先核验已有聚合服务，并与可用的官方直连路径比较，按讲解、生成、校验和 embedding 明确可用模型及处理用途。
仅比较合成资料时可先测现有入口；真实私有资料不因上游模型名知名或 API 可调用而准入。
聚合平台本身、转发方与真正上游分别登记处理地域、留存、训练、分包、删除/退出与可核验证据，
不能将上游厂商的官方数据政策直接套用到聚合平台。
供应商路由/别名如会静默切换上游，必须先取得可判定处理边界；无法判定时禁用真实资料路径。
质量较弱或信息不足时返回待处理/失败，不为了预算放宽来源、权限或质量门禁。
初始不额外部署通用第三方网关；先比较应用内部 Provider Adapter，保持替换边界。
Python 网关/worker 负责受限调用，API 负责权限、用途、预算准入、权威账本与结果接纳。
模型只能产生候选，不能自行写数据库或调用未授权工具。

载荷仅包含获准的最小证据包、题型/量规和必要约束；API 密钥由受控服务端加载，
不出现在 Web、任务历史、错误回执或可识别日志中。每个调用绑定资源版本、Job/步骤、
批准供应商及配置版本、预计/实际用量和最小错误类别，完整提示和输出不作为通用日志保存。
必要业务内容按资产目录保存并纳入清理；供应商留存与输入/输出各自核验。

步骤准入需与取消/删除原子协调，超时/重试/修复次数有上限；预算预留、实际费用与未知费用待对账区分。
取消后不新增准入调用，取消前已获准调用可能产生费用；未知回执不盲目重试导致重复费用。
是否供应商支持幂等、取消或 usage 回执均待核验，不能以平台 request ID 推定上游恰好一次。

备用供应商尚未批准时禁止静默降级外发；只能排队、返回部分可用或失败。
已确认用途缓存按权限域、内容/来源版本、模型与配置版本隔离，不跨私有用户复用。
每任务成本覆盖全部调用链，不从“同一供应商不同模型”推定独立校验已经有效。

## 供应商核验与成本

| 必需证据 | 当前状态 | 未具备时的路径 |
| --- | --- | --- |
| 平台/具体模型、实际路由、价格和额度 | 用户已提供平台模型别名；平台名称、实际上游/版本与报价待核验 | 用桩或合成资料定义调用契约，不编造每题成本 |
| 请求与处理地域、分包方、传出路径 | 未核验 | 真实资料保持禁用 |
| 输入/输出/日志留存、训练使用和删除/退出规则 | 未核验 | 真实资料保持禁用，不以“API 兼容”替代条款 |
| 任务用途、素材来源许可及用户告知 | 逐用途待核验 | 只在获准路径使用合成资料，不扩展为用户真实材料授权 |
| 限流、超时、重试、取消、usage 与计费边界 | 未测试 | 先隔离验证，计费未知单列待对账 |

模型费用暂建议分配 ¥180/月，来自总增量预算 ¥300 的提案，尚未批准此分配或供应商支出。
输入/输出/embedding 单价与实际计费单位待查，再测任务调用链总量；不提供未经核算的容量保证。

## Responses 兼容入口的核验规格

以 [OpenAI 官方 create 参考](https://developers.openai.com/api/reference/resources/responses/methods/create)
作接口对照，用户所述兼容性尚未通过请求验证。优先封装 Responses Provider Adapter，
先比较合成输入的非流式调用，再测试 SSE；不默认退回 Chat Completions 或自动改用未知上游。
业务只接收归一化候选，不依赖 SDK 的便利字段一定存在，也不把 HTTP 200 当生成已完成。

- 记录平台实际 model 别名、返回标识、请求标识、status、必要 usage 与错误类别；缺 usage 单列待对账。
- 核验 output item 类型及文本分段、拒绝、incomplete、failed、限流与超时；只在符合状态/结构/质量门禁后接纳。
- SSE 核验事件类型/终止条件、断流及重复片段；不把部分输出当成功，不因重连无条件重新启动付费调用。
- 建议显式请求 `store: false`、不启用后台任务/远端文件或未批准工具，不依赖远端 previous_response_id 保存私有上下文。
- OpenAI 官方参考中的 store 语义不能外推到聚合平台；必须核验该平台是否支持/忽略此字段，以及其独立日志/转发方留存。仅设置 false 不证明零留存。
- 核验结构化输出、模型参数支持及错误行为；不支持时返回明确配置错误，不能静默放松输出和质量规则。

仅用合成资料验证这些能力；未获取可核验处理条件前，不批准真实私有资料、学习记录或受限内容传输。

## 替换、回滚与完成节点

替换供应商先核验新条件、合法夹具质量/费用及响应契约，再对已批准用途灰度；
旧服务停止新调用并跟踪凭据撤销、输入/日志/分包副本退出清理。旧模型结果不能绕过版本或用途门禁。
失败时回滚只限仍有有效审批的旧服务/配置，否则停用外发，不回滚删除状态。

Q01/Q05/Q08 由 A/C 汇总、相关外部责任人核验；最迟在真实资料外发与相应功能前明确。
MinerU 许可及解析能力由 CL-010 接续，不与生成供应商审批混用。本文未请求现有 API、未使用真实资料、未提供供应商准入或费用测算结果。
